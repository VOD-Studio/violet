# Pagination

数字分页：首末页、当前页及其左右各一页，其余折成省略号，两侧是上一页、下一页。素材选择、表情管理这类一次一页的列表用它；表格页脚的「共几条 / 每页条数」是表格自己的页脚，页码部分可以放这个单元；不分页码、只往后加载用「加载更多」按钮。

```tsx
import { Pagination } from "@violet/ui";

<Pagination page={page} totalPages={totalPages} onPageChange={setPage} />
```

## API

继承 `nav` 的原生属性与 `ref`（不含 `children`、`onChange`）。

| 属性 | 作用 |
| --- | --- |
| `page` | 当前页，从 1 开始 |
| `totalPages` | 总页数；**不超过 1 时不渲染**（返回 `null`） |
| `onPageChange` | 点页码、上一页、下一页时回调目标页；点当前页也会回调该页 |

页码序列（相邻数 1）：

| 总页数 / 当前页 | 序列 |
| --- | --- |
| 5 / 3 | 1 2 3 4 5 |
| 20 / 1 | 1 2 … 20 |
| 20 / 3 | 1 2 3 4 … 20 |
| 20 / 10 | 1 … 9 10 11 … 20 |
| 20 / 18 | 1 … 17 18 19 20 |
| 20 / 20 | 1 … 19 20 |

当前页离首页（末页）只隔一页时，那一侧不出省略号。总页数少时也会出省略号（如 7 页的第 1 页是 `1 2 … 7`），序列只由当前页与总页数决定。

## 读屏与键盘

| 元素 | 契约 |
| --- | --- |
| 根 | `nav`，`aria-label` 默认「分页」，可传入覆盖（同一页有多个分页时区分用途） |
| 页码 | 原生 `button`，可访问名称「第 N 页」，当前页 `aria-current="page"` |
| 上一页、下一页 | 原生 `button`，名称「上一页」「下一页」；在首页、末页是 `aria-disabled="true"`：点击与 Enter、Space 都不回调，**但仍可聚焦**，翻到边界时焦点不会丢 |
| 省略号 | `aria-hidden` 的 `span`，不是按钮、不读出 |

Tab 顺序：上一页 → 各页码 → 下一页。

## 视觉

页码按钮最小 32×32、胶囊，等宽数字 13px（`--font-mono`，字体由宿主决定），次级色；悬停 `--muted` 凹陷底、文字变前景色；当前页前景色实心底、背景色字。上一页、下一页是 32 圆钮、16px 图标，禁用时 35% 透明度。按钮间距 4，整条在父容器里水平居中（放进 flex 页脚时按内容宽度收缩，由页脚决定左右对齐）。

底色与文字色 160ms 过渡；减弱动态（系统偏好与 `[data-motion="reduce"]` 两个作用域）下取消。强制颜色模式下当前页用 `Highlight`。

## 导入

React 从 `@violet/ui` 或 `@violet/ui/pagination` 导入；按需 CSS 使用 `@violet/ui/components/pagination.css`，不依赖其它单元样式。
