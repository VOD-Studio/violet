# 基础语法

文本样式、标题、列表、引用、代码块、图片、表格、输入规则与 Slash 菜单。数学公式、图块、人物卡片等专项能力见手册[首页](./README.md)对应章节。

## 文本样式

| 效果 | Markdown 语法 | 快捷键 | 备注 |
|---|---|---|---|
| 加粗 | `**文本**` | `Cmd/Ctrl+B` | |
| 斜体 | `*文本*` | `Cmd/Ctrl+I` | |
| 下划线 | 无 Markdown 表达 | `Cmd/Ctrl+U` | 仅存 content_html |
| 删除线 | `~文本~` 或 `~~文本~~` | `Cmd/Ctrl+Shift+S` | 保留 GFM 单、双波浪号语义 |
| 下标 | `H<sub>2</sub>O` | `Cmd/Ctrl+,` | 工具栏「下标」，与上标互斥 |
| 上标 | `x<sup>2</sup>` | `Cmd/Ctrl+.` | 工具栏「上标」，与下标互斥 |
| 行内代码 | `` `代码` `` | `Cmd/Ctrl+E` | |
| 高亮 | `==文本==` | 工具栏高亮按钮（多色） | 颜色仅存 content_html |
| 文字颜色 | 无 Markdown 表达 | **顶部工具栏色板** | 仅存 content_html |
| 链接 | `[文字](https://…)` | 工具栏/气泡菜单 | 裸 URL 自动识别为链接（autolink） |
| 对齐 | 无 Markdown 表达 | 工具栏（左/中/右/两端） | 作用于标题与段落 |

> 入口提示：颜色选择在**顶部工具栏色板**；气泡菜单（选中文本时浮出）只有「粗体 / 斜体 / 行内代码 / 链接」四项。

正文上下标使用原生 HTML，不把 `~文本~` 改成下标，也不新增 `^文本^` 方言。数学公式中的上下标仍使用 LaTeX 的 `_` 与 `^`。包含正文上下标的段落、标题和表格会按需导出 HTML 载体，保留混合格式与字面标点。

## 标题与目录

支持 H1–H4 四级标题，语法为 `# ` / `## ` / `### ` / `#### ` 加空格。

- 文章页自动渲染**目录（TOC）**，提取 **H2 / H3 / H4**（H1 不进目录），锚点可点击跳转，滚动时高亮当前章节。
- 正文内 `#`+空格快捷生成标题；H1–H3 也可走 Slash 菜单。

## 列表

无序列表（`-`/`*`/`+` 加空格）、有序列表（`1.` 加空格）、任务列表（`- [ ]` / `- [x]` 加空格）。

- 任务列表在文章页渲染为可读勾选框（只读）。
- 列表内 `Tab`/`Shift+Tab` 缩进/反缩进。

## 引用与分割线

引用块用 `> ` 行首触发；分割线用 `---` 触发。

### 提示块

支持 GitHub 的 `NOTE`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION` 五种提示块。标记必须位于引用块首行并独占一行，可带行尾空格或制表符：

```markdown
> [!NOTE]
> 补充说明，支持 **强调**。
>
> - 第一项
> - 第二项

> [!TIP]
> 操作建议。

> [!IMPORTANT]
> 需要注意的信息。

> [!WARNING]
> 操作风险。

> [!CAUTION]
> 可能造成损失的操作。
```

Slash 菜单可插入五种提示块，也可在已有提示块中切换类型。工具栏「解除提示块」只移除包装，保留正文。多段、列表与代码块可放入提示正文；普通引用、未知类型、转义标记以及代码中的示例不会升级为提示块。类型标题由编辑器和阅读端生成，不重复写入正文。

### 折叠内容

使用原生 `<details>/<summary>`，不新增冒号围栏方言：

```html
<details><summary>查看实验细节</summary><p>第一段 H<sub>2</sub>O。</p><p>第二段说明。</p></details>
```

Slash 菜单「折叠块」插入后默认展开并定位摘要。摘要和正文都可编辑，正文支持多段、列表、代码与嵌套折叠块；编辑器左侧按钮设置保存后的默认展开状态。工具栏「折叠块 / 解除折叠」可解除包装并保留内容。

阅读端使用浏览器原生交互：点击摘要或聚焦摘要后按 `Enter` / `Space` 切换；`<details open>` 表示默认展开。Markdown 导出保留完整 HTML，并将载体内换行编码为 `&#10;`，防止代码空行截断折叠结构。

## 代码块

```javascript
const a = 1;
```

- 行首输入 ` ``` ` 加语言名（如 `javascript`、`go`）再回车，或 Slash 菜单「代码块」插入。
- 编辑器右上角下拉切换语言；前台按语言高亮，并显示语言标签与复制按钮。
- common 预设外的高亮语言（dockerfile、nginx 等）按需动态加载。

### 可运行代码块

读者可在文章页就地执行的源码块。Slash 菜单「可运行代码块」插入，语言支持 python / node / go / rust / bun；Markdown 载体为带 `runnable` 标记的围栏块，info string 可携带 JSON 资源参数：

````markdown
```python runnable {"timeout_secs":10}
print("hello, violet")
```
````

`runnable` 与 `run` 标记等价；HTML 载体与资源参数的精确格式见[存储与有损](./storage.md)。普通代码块与可运行代码块可随时互相切换。

## 图片

- 工具栏「图片」下拉 / Slash 菜单「图片」→ 本地上传或素材库。
- 上传走分片通道（`purpose=post`），支持秒传与断点续传。
- 文章页自动走 `w=1200` 缩略（GIF 保动画），点击看原图。
- Markdown 语法 `![alt](url)` 同样有效。

## 表格

| 列 A | 列 B |
| --- | --- |
| 1 | 2 |

Slash 菜单或工具栏「表格」插入 3×3 空表（带表头）。光标进入表格后顶部出现表格工具栏：增删行列、合并/拆分单元格、删除整表。

## Markdown 快捷输入（输入规则）

输入即转换，无需菜单：

| 输入 | 得到 |
|---|---|
| `#`+空格 / `##` / `###` | 标题 |
| `>`+空格 | 引用块 |
| `-`+空格 / `*`+空格 / `1.`+空格 | 列表 |
| `- [ ]`+空格 | 任务列表 |
| ` ``` `+语言+回车 | 代码块 |
| `---` | 分割线 |
| `**文本**` `*文本*` `~~文本~~` `==文本==` `` `代码` `` | 行内样式 |
| `$$公式$$`（段内）/ `$$$公式$$$`（行首三美元） | 公式节点 |
| ` ```mermaid ` 围栏 | 流程图（图块，见[图块与流程图](./diagram.md)） |

> 单 `$公式$` 在键入时不会即时转换，但粘贴/MD 导入时有效；手动插入走 Slash 菜单最稳。

## Slash 菜单

任意位置输入 `/` 唤起，支持关键词/中文模糊搜索，按组显示：

- **基础**：正文、一/二/三级标题、脚注
- **列表**：无序、有序、任务列表
- **块**：引用、五种提示块、折叠块、代码块、可运行代码块、分割线、表格（3×3 带表头）
- **媒体**：行内公式、公式块、图片、流程图

> H4、对齐、颜色、链接、行内样式、撤销重做等不在 Slash 菜单——只在工具栏/气泡菜单。

### 脚注

「脚注」命令在当前位置插入引用，并将光标移到文末脚注正文；已有脚注会出现在「引用脚注」候选中，可再次引用同一正文。点击编辑器内的脚注引用可定位正文。阅读时每次引用都有独立 ID 和回链；插入、删除引用后编号与回链同步更新。

```markdown
第一次引用[^note]，再次引用同一脚注[^note]。

[^note]: 可编辑的 **富文本正文**。

    第二段正文，保留四空格缩进。
```
