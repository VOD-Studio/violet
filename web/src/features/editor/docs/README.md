# 文章编辑器手册

面向作者的完整功能参考，按主题分章。编辑器为 Tiptap 富文本（WYSIWYG），保存时双写：`content_html`（展示权威源，保留下划线/颜色/高亮/对齐等样式）与 `content_md`（Markdown 源，降级展示/导出用，有损——见[存储与有损](./storage.md)）。

**用法**：站内的每一章都是**真实渲染的演示**——数学公式章节渲染的就是真公式，图块章节画的就是真手绘图；逐章浏览即逐项比对渲染效果。文档源码位于 `web/src/features/editor/docs/`，也可复制 Markdown 源码贴入编辑器实测。
