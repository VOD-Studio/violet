## Parent

## What to build

写操作确认交互适配脚本场景,11 个写命令全部接入。

- `ConfirmWrite` 签名改为 `(确认 bool, 错误 error)`:
  - `--yes` → 直通返回 true
  - stdin 非 TTY 且无 `--yes` → 返回用法错误(退出码 2),提示加 `--yes`
  - TTY → 保持 y/N 提示,取消返回 false(打印「已取消」,退出码 0)
- 接入命令:song like/trash/disallow-recommend、album subscribe/unsubscribe、artist subscribe、playlist subscribe/create/delete/update-name/update-desc/update-tags/update-tracks(共 13 个 case)
- 「已删除/已更新」等动作确认消息保持 stdout(git/kubectl 惯例)
