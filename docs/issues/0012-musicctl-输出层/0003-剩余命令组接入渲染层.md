# Issue-0003:剩余命令组接入渲染层

## Parent

PRD:`../../prd/0012-musicctl-输出层.md`(user stories 2,10)

## What to build

song 组之外的命令组全部从 `PrintExec` 切换到 `RenderExec`,完成全 CLI 输出统一。

- album/artist/playlist/user/search/recommend/fm 七个包的 `PrintExec` → `RenderExec` 机械替换
- raw 路径(`PrintRaw`:album detail、artist albums、user detail/follows)保持现状
- proto 输出的 raw 命令(subscribe 类、follow-each-other、`PrintJSON` 直调)改走 `RenderExec` 等价分派
- search 多段响应(songs/albums/artists/playlists/users/mvs)验证分段表格渲染

## Acceptance criteria

- [ ] 七个包全部切换,`PrintExec` 无残留调用(可删除)
- [ ] `search --keyword 周杰伦` TTY 出分段表格
- [ ] `playlist tracks --id` / `album shelf` / `artist toplist` 等列表命令 TTY 出表格
- [ ] 各列表命令管道自动 JSON 且可被 `jq` 消费
- [ ] 真机 smoke:每包至少跑一个列表命令 + 一个单对象命令
