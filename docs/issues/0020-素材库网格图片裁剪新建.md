## What to build

素材库网格里**图片卡片** hover 时出「裁剪」icon（套用现有视频卡片「选帧设封面」Film icon 的模式），点击开裁剪弹窗。裁剪确认后**走标准上传新建一条素材记录**（本切片不涉及覆盖，覆盖在 Issue-0021）。

裁剪入口仅图片显示，非图片（视频/音频/文件）不出 icon。多文件上传 Modal 完全不动——素材库本就支持多种素材上传，本切片只给已上传的图片补「再裁剪」能力。

## 实现指引

参考 plan 的 Task F12 的 Step 1-3（MediaGrid icon + admin.media.tsx 编排），**只做新建路径、不做覆盖 checkbox**。

裁剪 Modal 不直接复用 `CropUploadDialog`——因为素材库场景需要后续扩展「覆盖」checkbox（Issue-0021），而 CropUploadDialog 服务头像/封面（无覆盖）。素材库用 `ImageCropper` + 自定义 footer Modal 直接编排，确认时手动调 cropImageToBlob + uploadFile。

icon 位置参考 `MediaGrid.tsx` 现有视频 `onPickCover` 块（line ~96-105），裁剪块放它之后、`onEdit` 之前。
