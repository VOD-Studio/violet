# T5 [tweets] OG 卡片组件与推文接入

前置：T2（DTO 内嵌 link_cards）、T4（tokenizer 确定正文 URL 集合）。

## 目标

通用 OG 卡片展示组件（`shared/ui/link-card`）接入推文卡片：正文下方每链一卡，消费 DTO `link_cards`，无数据不渲染。

## 改动点

- `web/src/shared/ui/link-card/`：展示组件——封面（比例钳制、`contentImageUrl` 缩略）、标题、描述（截断）、域名；整卡 `<a target="_blank" rel="noopener noreferrer">`；空字段降级（无封面纯文本卡）；语义 token，功能圆角 ≤ rounded-2xl，无硬投影。含组件测试。
- `web/src/features/tweets/ui/TweetCard.tsx`：正文后渲染 `tweet.link_cards`（每链一卡，顺序按正文出现）；卡片点击阻止外层导航。
- 详情页正文区同样接入（时间线/主页/详情一致）；引用卡片、外链推文不动。
- SSR 直出验证：服务端渲染含卡片标记的 HTML。

## 验收

- 浏览器实测：有 OG 卡（封面+标题+域名）、纯文本卡、无卡降级三种形态；键盘聚焦环完整；暗色主题正常。
- SSR 响应 HTML 含卡片内容（非客户端补抓）。
- `web-test`、`web-typecheck`、Biome 全绿。
