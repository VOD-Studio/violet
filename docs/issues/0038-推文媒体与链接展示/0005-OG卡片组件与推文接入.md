# T5 [tweets] OG 卡片组件与推文接入

前置：T2（DTO 内嵌 link_cards）、T4（tokenizer 确定正文 URL 集合）。

## 目标

通用 OG 卡片由 `@violet/ui` 提供纯展示单元；`entities/link-preview` 管理站点数据与异步回填，推文正文下方每链一卡。

## 改动点

- `web/packages/ui/src/components/link-card/`：X 式小卡片，原生 anchor、封面、标题、描述、域名；图片失败移除图位，重复文案去重，正常描边保留且 hover 不高亮。根入口、清单、同源文档及 tarball 消费验收一起交付。
- `web/src/entities/link-preview/`：公开 DTO、URL 级共享缓存与批量 lookup，仅 pending 每 2 秒继续，完成/失败/卸载停止。`TweetCard` 按正文顺序接入，快照由 DTO 提供，点击阻止外层导航。
- 详情页正文区同样接入（时间线/主页/详情一致）；引用卡片、外链推文不动。
- SSR 直出验证：服务端渲染含卡片标记的 HTML。

## 验收

- 浏览器实测：有 OG 卡（封面+标题+域名）、纯文本卡、无卡降级三种形态；键盘聚焦环完整；暗色主题正常。
- 发布后无需刷新即可补出卡片；403 等终态不出空卡、不继续轮询；同 URL 多消费方共享状态。
- SSR 响应 HTML 含卡片内容（非客户端补抓）。
- `web-test`、`web-typecheck`、Biome 全绿。
