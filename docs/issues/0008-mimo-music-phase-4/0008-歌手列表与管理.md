# Issue-0008：歌手列表浏览与收藏管理

## Parent

PRD：`../../prd/0008-mimo-music-phase-4.md`（user stories 44-46；Implementation Decisions - 歌手扩展）

## What to build

补充歌手的全局浏览和写操作接口：热门歌手列表、歌手分类列表、收藏/取消收藏歌手。

热门歌手和分类列表是全局浏览（非按 artistID 查），放在 Artist 能力域作为列表方法。收藏是写操作，需登录态。

在 `provider.Artist` 接口新增方法：`TopArtists(ctx, limit, offset)`（热门歌手）/ `Categories(ctx)`（歌手分类列表）/ `Subscribe(ctx, artistID, cookie)`（收藏/取消，toggle）。

netease 实现：TopArtists 走 `/weapi/artist/top`；Categories 走 `/weapi/artist/list`（带 cat 参数为分类，不带为列表）；Subscribe 走 `/weapi/artist/sub`。

service 层：TopArtists/Categories 做缓存（24h）；Subscribe 不缓存走 cookie 轮换。

HTTP 端点：GET /api/v1/artists/top、/categories、POST /api/v1/artists/{id}/subscribe（需登录）。

SDK 同步增加。
