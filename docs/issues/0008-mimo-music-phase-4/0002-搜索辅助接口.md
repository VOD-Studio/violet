## What to build

补充搜索周边的辅助接口：搜索建议、热搜列表（简略）、热搜列表（详细）、默认搜索关键词。独立于 0001 的 type 扩展，但同属 SearchService。

每个接口是一个 endpoint 声明 + proto rpc：

- **Suggest**（搜索建议）：`SearchService.Suggest`，请求 `SuggestRequest{keyword}`，响应 `SuggestResponse{repeated string songs/albums/artists/...}`。endpoint 网易云 `/weapi/search/suggest/keyword`，`CachePolicy` TTL 10min。
- **Hot**（热搜简略）：`SearchService.Hot`，无请求参数，响应 `HotResponse{repeated HotKeyword}`。endpoint `/api/search/hot`，TTL 10min。
- **HotDetail**（热搜详细）：`SearchService.HotDetail`，响应 `HotDetailResponse{repeated HotDetail}`（含 iconUrl/cover 等完整字段）。endpoint `/api/search/hot/detail`，TTL 10min。
- **DefaultKeyword**（默认词）：`SearchService.DefaultKeyword`，响应 `DefaultKeywordResponse{string keyword}`。endpoint `/api/search/defaultword`，TTL 1h（变化低频）。

各接口的 `Meta.Auth = AuthAnonymous`（搜索辅助不需登录）。

新 proto message：`HotKeyword`（first/searchWord/iconUrl）、`HotDetail`（HotKeyword + cover/score/position）。这些是搜索专属，不提炼到 model 层（无跨领域复用）。

具体网易云端点以实际可用为准。
