# Issue-0002：搜索辅助接口（建议/热搜/默认词）

## Parent

PRD：`../../prd/0008-mimo-music-phase-4.md`（user stories 8-11；Implementation Decisions - 搜索 type 扩展）

## What to build

补充搜索周边的辅助接口：搜索建议、热搜列表（简略）、热搜列表（详细）、默认搜索关键词。这些是搜索体验的标配，独立于 0001 的 type 扩展，但同属 Search 能力域。

`provider.Search` 接口新增方法：`Suggest(ctx, keyword)` / `Hot(ctx)` / `HotDetail(ctx)` / `DefaultKeyword(ctx)`。各自返回对应的 Result 类型（建议词列表、热搜词列表、热搜详情列表、默认关键词字符串）。

netease 实现：建议用 `/weapi/search/suggest/keyword`（或 `/api/search/suggest`），热搜简略用 `/api/search/hot`，热搜详细用 `/api/search/hot/detail`，默认词用 `/api/search/defaultword`（或对应端点）。具体端点以网易云实际可用为准。

service 层：建议/热搜做缓存（10 分钟，对齐搜索结果），默认词做缓存（1 小时，变化低频）。

HTTP 端点：`GET /api/v1/search/suggest` / `GET /api/v1/search/hot` / `GET /api/v1/search/hot/detail` / `GET /api/v1/search/default`。

SDK 同步增加对应方法。
