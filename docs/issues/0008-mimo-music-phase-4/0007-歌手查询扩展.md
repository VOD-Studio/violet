# Issue-0007：歌手查询扩展

## Parent

PRD：`../../prd/0008-mimo-music-phase-4.md`（user stories 38-43, 47-48；Implementation Decisions - 歌手扩展）
前置：地基阶段完成（ArtistService 已存在，含 GetArtist rpc；Artist 实体在首批 5 实体中）

## What to build

扩展现有 `ArtistService`，补充歌手的完整查询接口：全部歌曲（分页）、热门 50 首、MV 列表、专辑列表、描述、相似歌手、动态信息、视频、粉丝数。

proto `ArtistService` 加 rpc：

- **AllSongs**（分页全曲）：`AllSongsRequest{artist_id, offset, limit, order}`，响应 `repeated Song` + 分页。网易云 `/weapi/v1/artist/songs`。`MapResponse` 调 `model.MapSongs`。
- **TopSongs**（热门 50）：`TopSongsRequest{artist_id}`，响应 `repeated Song`。网易云 `/weapi/artist/top/song`。调 `model.MapSongs`。
- **MVs**（MV 列表）：`MVsRequest{artist_id, offset, limit}`，响应 `repeated MV` + 分页。网易云 `/weapi/artist/mvs`。
- **Albums**（专辑列表）：`AlbumsRequest{artist_id, offset, limit}`，响应 `repeated Album` + 分页。网易云 `/weapi/artist/albums`。调 `model.MapAlbums`。
- **Desc**（详细描述）：`DescRequest{artist_id}`，响应 `string`。网易云 `/weapi/artist/introduction/desc`。
- **Similar**（相似歌手）：`SimilarRequest{artist_id}`，响应 `repeated Artist`。网易云 `/weapi/discovery/simiArtist`。调 `model.MapArtists`。
- **Dynamic**（动态信息）：`DynamicRequest{artist_id}`，响应 `ArtistDynamic`。网易云 `/weapi/artist/detail/dynamic`。
- **Videos**（视频）：`VideosRequest{artist_id, offset, limit}`，响应 `repeated Video` + 分页。网易云 `/weapi/artist/video/list`。
- **Fans**（粉丝数）：`FansRequest{artist_id}`，响应 `int64`。网易云 `/weapi/artist/fans/count`。

全部 `CachePolicy` TTL 24h，`AuthAnonymous`。

新建 proto message + model 实体判断：MV 和 Video 本期首次出现。若字段少（只 id/name/封面），proto 定义最小 message，暂不提炼 model 层；若字段多（被歌手 MV 列表和未来搜索 MV 复用），提炼为 `model.MV` / `model.Video`。判断标准：该实体被第二个领域复用就提炼——搜索 type=1004（MV）在 0001 已定义最小 MV message，此处若字段对齐则复用，否则充实。
