# Issue-0007：歌手查询扩展

## Parent

PRD：`../../prd/0008-mimo-music-phase-4.md`（user stories 38-43, 47-48；Implementation Decisions - 歌手扩展）

## What to build

扩展现有 Artist 能力域（只有 Info 方法），补充歌手的完整查询接口：全部歌曲（分页）、热门 50 首、MV 列表、专辑列表、描述、相似歌手、动态信息、视频、粉丝数。

在 `provider.Artist` 接口新增方法：`AllSongs(ctx, artistID, limit, offset)`（分页全曲）/ `TopSongs(ctx, artistID)`（热门 50）/ `MVs(ctx, artistID, limit, offset)` / `Albums(ctx, artistID, limit, offset)` / `Desc(ctx, artistID)`（详细描述）/ `Similar(ctx, artistID)`（相似歌手）/ `Dynamic(ctx, artistID)`（动态信息）/ `Videos(ctx, artistID, limit, offset)` / `Fans(ctx, artistID)`（粉丝数）。

netease 实现：AllSongs 走 `/weapi/v1/artist/songs`；TopSongs 走 `/weapi/artist/top/song`；MVs 走 `/weapi/artist/mvs`；Albums 走 `/weapi/artist/albums`；Desc 走 `/weapi/artist/introduction/desc`；Similar 走 `/weapi/discovery/simiArtist`；Dynamic 走 `/weapi/artist/detail/dynamic`；Videos 走 `/weapi/artist/video/list`；Fans 走 `/weapi/artist/fans/count`。

service 层：全部做缓存（24h，歌手资料低频变化）。分页接口（AllSongs/MVs/Albums/Videos）带 Total 字段。

HTTP 端点：GET /api/v1/artists/{id}/songs、/top、/mvs、/albums、/desc、/similar、/dynamic、/videos、/fans。

SDK 同步增加。

## Acceptance criteria

- [ ] Artist 子接口新增 AllSongs / TopSongs / MVs / Albums / Desc / Similar / Dynamic / Videos / Fans 九个方法
- [ ] 各方法有对应 Result 类型，分页接口带 Total
- [ ] `provider/netease/artist_extra.go`（或 artist.go 扩展）实现九个方法
- [ ] service 层缓存（24h）
- [ ] 九个 HTTP 端点注册到 router
- [ ] SDK 九个方法 + DTO
- [ ] service 层 mock 测试：缓存命中/未命中
- [ ] netease converter 测试
- [ ] 所有导出符号有 godoc 注释

## Blocked by

无 —— Artist 能力域已存在（Info 方法），本切片是扩展。与歌单模块互相独立，可并行。
