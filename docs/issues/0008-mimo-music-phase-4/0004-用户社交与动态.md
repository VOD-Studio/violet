## What to build

在 0003 建好的 UserService 上扩展社交关系与活动流接口：关注列表、粉丝列表、动态、播放记录、等级信息。

proto `UserService` 加 rpc：Follows / Followeds / Events / Record / Level。

- **Follows**（关注列表）：`FollowsRequest{user_id, offset, limit}`，响应 `repeated User` + 分页。网易云 `/weapi/user/getfollows`。
- **Followeds**（粉丝列表）：同上，网易云 `/weapi/user/getfolloweds`。
- **Events**（动态）：`EventsRequest{user_id, offset, limit}`，响应 `repeated Event`。网易云 `/weapi/event/get`。Event message 本期在 proto 里定义（网易云动态结构复杂），若字段足够多提炼为 model.Event 留待判断——否则 endpoint raw struct 声明。
- **Record**（播放记录）：`RecordRequest{user_id, type}`（type 0=本周 1=所有），响应 `repeated PlayRecord`（含 song + play_count）。网易云 `/weapi/v1/play/record`。`MapResponse` 调 `model.MapSong` 复用。
- **Level**（等级信息）：`LevelRequest{user_id}`，响应 `UserLevel{level, point, ...}`。网易云 `/weapi/user/level`。

缓存：关注/粉丝/等级 TTL 24h；动态和播放记录 TTL 10min（相对活跃）。全部 `AuthAnonymous`。

`MapResponse` 调 `model.MapUser`（关注/粉丝列表）、`model.MapSong`（播放记录里的 song）复用。
