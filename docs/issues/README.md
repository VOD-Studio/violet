# issues 目录

本目录存放按 PRD 或功能主题分组的历史任务/issue 记录。

## 子目录

| 目录 | 说明 |
|---|---|
| `0004-图片区域裁剪上传/` | 图片裁剪与素材库相关任务（无对应 PRD），编号 `0001-0007`。 |
| `0005-图块流程图/` | 图块与流程图渲染系列任务。 |
| `0038-推文媒体与链接展示/` | PRD-0038 的拆分任务，编号 `0001-0006`。 |

## 编号规则

- 每个子目录内独立从 `0001` 开始编号。
- 编号仅保证子目录内连续，不同子目录之间允许重复。
- 文件名格式：`0001-<任务简述>.md`。
