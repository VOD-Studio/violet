# Issue-0007：批注开关预留（文章级 + 站点级）

## Parent

PRD-0001（`docs/prd/0001-锚点批注评论.md`）

## What to build

预留「整篇文章 / 全站」关闭批注功能的能力。本期只建后端字段 + 前端读取条件渲染，**不做 admin 配置 UI**（PRD 已声明 Out of Scope）。目的是让批注功能日后可被干净关闭（如纯公告文章、站点降级），关闭时不残留半成品 UI。

端到端行为：
- 后端：`posts` 表新增 `allow_annotations BOOLEAN DEFAULT true`；站点设置新增 `annotations_enabled BOOLEAN DEFAULT true`。
- `GET /posts/{slug}` DTO 返回 `allow_annotations`；站点设置接口返回 `annotations_enabled`。
- 前端文章详情页读取这两个字段：
  - 文章级 `allow_annotations === false` → 不渲染 `AnnotationLayer` / `AnnotationSidebar` / `FloatingToolbar`；底部 `CommentSection` 照常。
  - 站点级 `annotations_enabled === false` → 全站同上。
  - 两个开关任一为 false 即关闭批注（AND 语义，更严的优先）。
- 创建侧：批注关闭时，`POST /comments` 携带 anchor → 后端拒绝（400，「该文章未开启批注」）；防止绕过前端。

## Acceptance criteria

- [ ] migration：`posts` 表加 `allow_annotations BOOLEAN NOT NULL DEFAULT true`；站点设置表（确认是哪个表，可能是 `site_settings`）加 `annotations_enabled BOOLEAN NOT NULL DEFAULT true`。
- [ ] GORM 模型 + domain 实体同步字段。
- [ ] `GET /posts/{slug}` DTO 加 `allow_annotations`；站点设置接口加 `annotations_enabled`。
- [ ] `POST /comments` handler 校验：若 `anchor != nil` 且 (`post.allow_annotations == false` 或站点 `annotations_enabled == false`) → 400。
- [ ] 前端文章详情页读取两字段，条件渲染（关闭时不渲染 Issue-0005/0006 的组件，`CommentSection` 照常）。
- [ ] AND 语义：两开关任一 false 即关闭。
- [ ] 关闭是干净的：无高亮、无右侧栏、无浮动工具条、底部评论区照常（PRD story 31）。
- [ ] 测试：
  - 后端：开关关闭时 `POST /comments` 带 anchor → 400；不带 anchor → 正常。
  - 前端：mock `allow_annotations=false` → 不渲染 AnnotationLayer/Sidebar/Toolbar（RTL 断言 DOM 不存在）。
- [ ] **不做** admin 配置界面（PRD Out of Scope）；字段本期靠 migration 默认值 + 后续 PRD 补 admin UI。
