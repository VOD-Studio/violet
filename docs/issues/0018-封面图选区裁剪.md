# Issue-0018：封面图选区裁剪

## Parent

spec：`docs/superpowers/specs/2026-07-07-image-region-crop-upload-design.md`
plan：`docs/superpowers/plans/2026-07-07-image-region-crop-upload.md`

## What to build

把裁剪能力接入封面图场景。`Cover` 组件当前是纯素材库选择（选完直接 `onChange(url)`），改为：MediaPicker 单选确认后**先进裁剪弹窗**，确认才回填。

裁剪结果按图片类型分流（复用 Issue-0016/0017 的 CropUploadDialog 已支持的两种 kind）：
- 静态图：canvas 重编码 → 上传为新素材（purpose=cover）→ onChange(新 url)
- GIF：`withCrop(素材url, rect)` → onChange（不产生新素材，URL 带 `?crop=`）

Cover 预览区用 `CroppedImage` 替换 `<img>`，自动解析 `?crop=` 聚焦选区。**封面无「覆盖原图」选项**（封面是从素材库选的引用，覆盖语义不适用）。
