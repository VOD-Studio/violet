# Issue-0005：B3 更新日志（releases 接口端到端，含 Redis 缓存）

## Parent

PRD-0009（`../../prd/0009-about-redesign.md`）

## What to build

实现 B3 更新日志区块——整个 PRD 最复杂的切片。后端代理 GitHub Releases API + Redis 缓存 + 解析 emoji 分类标签 + 降级 → 前台版本时间线卡片区块。

**数据源决策**（PRD-0009 已定）：GitHub Releases API 是 release-please 发版的天然副产物（`deploy.yml:262-297` 已从 CHANGELOG 抽段落生成 Release notes），发版即更新、零手工维护。后端**复用现有 `github_token`**（settings 已有，admin-only）调 GitHub API 提限流到 5000/小时，结果用 **Redis 缓存（~1h）** 解决访客直连必爆限流。对齐并增强现有 `/api/v1/github/contributions` 代理模式（后者无缓存，本切片是加缓存层的演进版）。

**呈现对齐业界最佳实践（个人博客变体，PRD-0009 已研究）**：版本时间线卡片 + 日期戳 + 分类标签直接从 release body 的 emoji 行解析（release-please 已把 commit 类型映射成 ✨新增/🐛修复/♻️重构等，映射成带颜色 Chip）+ Breaking change 醒目标记。保留技术事实（受众是技术读者），舍弃截图/GIF。

端到端切片：后端 `GET /api/v1/releases`（provider 拉 releases → 解析分类 → Redis 缓存 → 失败降级）→ 前台 `useReleases` hook → 时间线卡片区块。

## Acceptance criteria

### 后端 releases 域模块（DDD 四层）
- [ ] `domain/releases`：Release 聚合 / DTO（version / published_at / categories[{emoji,label,items[]}] / breaking）
- [ ] `GitHubProvider` 端口扩展 `GetReleases(ctx, owner, repo, token)`（优先复用现有 `infrastructure/github/adapter.go`，或独立 `ReleaseProvider` 端口视解耦度）
- [ ] `application/releases`：调 provider 拉 releases → 解析 body emoji 行成分类标签 → 检测 breaking → 组装 DTO
- [ ] **Redis 缓存**：成功结果写缓存（key 如 `releases:cache`，TTL ~1h）；GitHub 失败/限流时回退读缓存（即使过期，stale 兜底）；无缓存且失败时返回空列表不 500
- [ ] 版本注入：接口顺带返回 `current_version`（GitHub Releases 最新一条，或读 `.release-please-manifest.json`）
- [ ] 路由 `GET /api/v1/releases` 公开无需鉴权
- [ ] 仓库 owner/repo 来源：从 `github_username` 推导或新增 settings 字段（实现时定，倾向复用 username + 配置项 repo 名）

### 前台区块（features/about/ui + api）
- [ ] `useReleases` hook（TanStack Query）
- [ ] 时间线卡片：每版本一张卡，版本号 + 发布日期 + 分类 Chip（emoji + 带颜色 label）+ notes 条目
- [ ] Breaking change 醒目标记（红/橙）
- [ ] 接口失败/空时优雅降级（显示"暂无更新日志"或骨架，不崩）

### 测试（Seam 2 · 后端 handler 行为）
- [ ] `GET /api/v1/releases` 调通：mock provider 返回 release body，断言解析出正确分类标签 + breaking 标记
- [ ] GitHub 失败/限流时降级：返回缓存或空，不 500
- [ ] token 缺失（username/token 空）时降级：返回空，不调外部 API（对齐现有 `GetContributions` 的 `username == ""` 短路模式）
- [ ] 缓存命中：不重复调 provider

### 验收
- [ ] 前台更新日志区块正确展示版本时间线 + 分类标签
- [ ] GitHub API 不可用时不影响整页（降级正常）
- [ ] `make api-test` / 各 lint 全绿
- [ ] 修改 SQL 后 `make sqlc`、修改 DI 后 `make wire`（若涉及）
