# Issue-0004：B2 站点生命体征（public-stats 接口端到端）

## Parent

PRD-0009（`../../prd/0009-about-redesign.md`）

## What to build

实现 B2 站点生命体征（Live Stats）区块：后端新增**公开只读** stats 接口 → 前台跳动数字区块。

现有 `/admin/stats`（`GetDashboardStats`）是 admin-only，不能直接给前台用。本 issue 新增**公开只读变体** `GetPublicStats`，只暴露安全字段（文章数 / 总字数 / 评论数 / 运行天数），**绝不泄露** admin 维度的敏感数据（如后台统计中的细粒度维度）。

端到端切片：后端公开 `GET /api/v1/stats`（白名单字段）→ 前台 `usePublicStats` hook → Live Stats 跳动数字区块（motion 驱动数字滚动动画）。

## Acceptance criteria

### 后端公开只读接口（stats 域）
- [ ] 新增 `GetPublicStats` application 用例：聚合文章数（已发布）/ 总字数（已发布 posts 正文）/ 评论数（approved）/ 运行天数（从站点上线日或配置项计算）
- [ ] 路由 `GET /api/v1/stats` **公开无需鉴权**（参照 `GET /api/v1/settings` / `/github/contributions` 的公开端点注册位置）
- [ ] **字段白名单严格**：只返回 `posts_count` / `total_words` / `comments_count` / `uptime_days`，admin-only 维度一律不出现
- [ ] 运行天数锚点：需定义"上线日"来源（settings 新增 `site_launched_at` 字段，或用最早 post 创建时间兜底）

### 前台区块（features/about/ui + api）
- [ ] `usePublicStats` hook（TanStack Query，对齐现有 hook 惯例与 staleTime）
- [ ] Live Stats 区块：文章数 / 总字数 / 评论数 / 运行天数，跳动数字动画（可复用 react-bits `Counter` 或 motion）
- [ ] 接口失败时优雅降级（不显示数字或占位，不导致整页崩）

### 测试（Seam 2 · 后端 handler 行为）
- [ ] `GET /api/v1/stats` 返回正确聚合数据（httptest + mock store）
- [ ] **公开接口不泄露 admin 字段**：响应中无任何 admin-only 维度（关键安全断言）
- [ ] 聚合口径正确：只统计已发布文章 / approved 评论

### 验收
- [ ] 前台 Live Stats 区块正确显示跳动数字
- [ ] 公开接口响应字段最小化、无敏感泄露
- [ ] `make api-test` / 各 lint 全绿
