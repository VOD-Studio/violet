# Issue-0001：后台设置 IA 重构（导航子菜单 + 拆设置子页）

## Parent

PRD-0009（`../../prd/0009-about-redesign.md`）

## What to build

把现有「站点设置」单页大表单（`admin.settings.tsx`，8 个 section 纵向堆叠）拆成「设置」分组下的多个子页面，并在侧边栏支持可折叠子菜单。这是整个 About 重设计的**地基 prefactor**——不先理顺设置 IA，后续 About 配置子页无处安放。

端到端切片：导航配置加 `children` 能力 → 侧边栏/移动端导航渲染折叠子菜单 → 现有单页大表单按职责拆成独立子路由（基础 / 认证 / GitHub / LLM / 代码运行器），各子页独立表单、独立保存、互不干扰。本 issue **不新增任何设置字段**，只做结构重排（重构与功能分离的 prefactor）。

## Acceptance criteria

### 导航配置（shared/admin-layout）
- [ ] `AdminNavConfig.ts`：`AdminNavItem` 新增可选 `children?: AdminNavItem[]`
- [ ] 「站点设置」从叶子项升级为父项，子项为各设置子页路由
- [ ] 父项可见性 = 任一子项可见（权限沿用现有 `permissions` 字段，满足任一即显示，超管通配短路不变）

### 侧边栏渲染（admin-layout/ui）
- [ ] `AdminSidebar.tsx`：渲染父项时支持折叠/展开子菜单
- [ ] `AdminMobileNav.tsx`：同步支持折叠子菜单（两处共用 `AdminNavConfig`，渲染逻辑一致）
- [ ] 折叠状态有持久化（如 `admin-sidebar-store`，对齐现有惯例）
- [ ] 当前路由命中某子项时，父项自动展开并高亮子项

### 设置子页拆分
- [ ] 现有 `admin.settings.tsx` 拆为多个子路由文件（如 `admin.settings.general` / `admin.settings.auth` / `admin.settings.github` / `admin.settings.llm` / `admin.settings.code-runner`）
- [ ] 每个子页独立 `useForm`、独立「保存」按钮、独立 `PUT /admin/settings`（部分更新，指针字段）
- [ ] 拆分后**不丢任何现有设置项**（逐项核对原 8-section 的所有字段都落到某个子页）
- [ ] 关于页配置（`about_config`）的子页占位由 Issue-0002 接入，本 issue 仅预留导航位置即可（或完全不建该子页，留给 Issue-0002）

### 验收
- [ ] 折叠展开交互正常，移动端与桌面端一致
- [ ] 各子页独立保存生效，互不影响
- [ ] `make web-typecheck` + `make web-test` 全绿
- [ ] `make web-lint`（Biome）全绿

## Blocked by

None - 可立即开始（地基，无前置依赖）。
