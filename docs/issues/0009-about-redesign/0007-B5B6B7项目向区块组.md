# Issue-0007：B5 / B6 / B7 项目向区块组

## Parent

PRD-0009（`../../prd/0009-about-redesign.md`）

## What to build

实现 B 线剩余三个项目向区块（均为轻量信息展示，合并为一个 issue）：

- **B5 项目技术栈**：造这个博客用了什么（Go / React / PostgreSQL / Redis / Vite / Tailwind 等），每个带图标 + 用途说明（区别于 A3 的"博主技能"——这是"项目用了什么造出来"）
- **B6 "这座博客的数字"**：代码行数 / commit 数 / 部署次数等针对本项目的聚合数字
- **B7 开源致谢**：造这个博客用到的开源项目列表

### 数据源说明（B6 待实现时定）

B6 的数据源在 PRD-0009 标记为"待定"，有两种候选，实现时选择：
- **候选甲**：扩展 Issue-0004 的 public-stats 接口，加 `code_lines` / `commit_count` / `deploy_count` 字段（后端读 git 元信息或配置项）。
- **候选乙**：纯 settings 手工维护这几个数字。

倾向候选甲（保持"活数据"调性），但若后端读 git 元信息成本过高，降级为候选乙。决策在实现本 issue 时落地，记录于本 issue 或 ADR。

端到端切片：后端补 B5/B7 所需 settings 字段 + B6 数据源（扩 stats 或 settings）→ 前台三个区块组件 → 接入骨架渲染。

## Acceptance criteria
