## What to build

在前 4 个 issue 的地基上，把 15 个已实现接口迁移到新架构（endpoint 声明 + grpc service），迁移 wire 装配，然后删除全部旧产物。这是地基阶段的收尾——迁移完成后，mimo-music 跑在新架构上。

### 15 个接口的 endpoint 声明

每个接口在 `internal/netease/endpoint/<域>/<接口>.go` 一个包级 `var`，含 Meta + CachePolicy + MapRequest + MapResponse：

| 域 | 接口 | Meta.Crypto | Meta.Auth | CachePolicy |
|---|---|---|---|---|
| auth | SendCaptcha | weapi | LoggedIn | nil |
| auth | LoginByCellphone | weapi | LoggedIn | nil |
| auth | LoginQrcode | none(postJSON) | Anonymous | nil |
| auth | CheckQrcode | none(postJSON) | Anonymous | nil |
| auth | LoginStatus | weapi | LoggedIn | nil |
| auth | Logout | weapi | LoggedIn | nil |
| playlist | GetPlaylist | weapi | Anonymous | key=`playlist:detail:{id}` TTL=24h |
| song | GetSongDetail | weapi | Anonymous | key=`song:detail:{id}` TTL=24h |
| song | GetSongURL | weapi | Anonymous | key=`song:url:{id}:{level}` TTL=30min |
| song | GetLyric | weapi | Anonymous | key=`song:lyric:{id}` TTL=24h |
| search | Search | none(apiGet) | Anonymous | key=`search:{keyword}:{limit}` TTL=10min |
| album | GetAlbum | weapi | Anonymous | key=`album:detail:{id}` TTL=24h |
| artist | GetArtist | weapi | Anonymous | key=`artist:info:{id}` TTL=24h |
| recommend | GetDailyRecommend | weapi | LoggedIn | key=`recommend:daily` TTL=1h |
| fm | GetPersonalFM | weapi | LoggedIn | key=`fm:personal` TTL=30min |

- `MapResponse` 调 model 层 map 函数复用（GetSongDetail 调 model.MapSongs，GetPlaylist 调 model.MapPlaylist，等）。
- `MapRequest` 构造网易云入参（如歌曲详情的 `c:"[...]"` 格式、歌单的 `{id,n:1000,s:8}`）。
- 登录类接口（captcha/login/qrcode）创建新 session，不走 GetAvailable，直接 Save——路径从旧 services.go 迁移。

### grpc service impl

`internal/service/<域>.go`：每个方法恒一行 `return engine.Execute(s.engine, ctx, <域>endpoint.<Rpc>, req)`。service 持有 `*engine.Engine`，不持有编排状态。

### wire 装配迁移

`internal/bootstrap/wire.go`：
- InfraSet 基本不动（redis/cache/store/metrics/logger）
- ProviderSet 重构：去掉旧 8 个能力桥接函数（ProvideAuth 等），换成 engine 装配 + 各 grpc service 装配
- `InitializeServer(cfg)` 装配链改为：logger → engine（含 session/cache/crypto/transport）→ 各 grpc service → grpc server + gateway mux

### 删除旧产物（ADR 第 12 节）

迁移验证通过后删除：

- `provider/`（整个目录：provider.go/registry.go/converter.go/decorator.go/options.go/cache.go/session.go/logger.go + netease/）
- `internal/server/`（router/handler/response/middleware）
- `openapi/` + `openapi.json` + `cmd/export-openapi/`
- `service/`（旧厚编排层，已被 internal/service/ 取代）
- `model/`（旧 DTO，已被 internal/netease/model/ 取代）
- chi 依赖从 go.mod 移除
- kin-openapi 依赖从 go.mod 移除（OpenAPI 改由 proto 生成）
