# Issue-0004：领域模型层首批 5 实体

## Parent

PRD：`../../prd/0009-mimo-music-foundation.md`（Solution 第 4 步）
关联：[架构 ADR 第 3.2 节](../../adr/mimo-music-architecture.md)

## What to build

从现有 `provider/netease/converter.go` + `model/` 提炼，建立 `internal/netease/model/` 领域映射层。首批 5 实体：Song / Artist / Album / Playlist / User。每个实体定义「网易云原始 JSON 的 struct 镜像 + map 到 proto 的函数」，写一次后全局复用。

这是「该复用的复用」的落点——把 15 个接口的响应映射从「每个接口从零写」塌缩为「调 map 函数组装」。

### 提炼来源与改造

现有 `converter.go`（166 行）已有部分映射逻辑（toSongResult / toModelSong / joinArtists / joinArtistsRaw），但转成的是 `provider.*Result`（旧类型）。新架构转成 proto message（`gen/go` 生成的 `pb.Song` 等）。

同时消除现有双套类型：`model/`（Song/Playlist/SearchResult/Lyrics/Session）与 `provider.*Result`（SongResult/ArtistResult/AlbumResult）字段重复——统一为 proto message（契约）+ model 层 raw struct（网易云原始镜像）+ map 函数（转换）。

### 5 个实体文件

- `song.go`：`raw.Song` struct（镜像网易云 JSON 缩写字段：id/name/ar/al/dt/fee/al.picUrl 等）+ `MapSong(raw.Song) *pb.Song` + `MapSongs([]raw.Song) []*pb.Song`。从 converter.go 的 toModelSong + joinArtists 合并提炼（joinArtists/joinArtistsRaw 是重复逻辑，合并为一个 MapArtist）。
- `artist.go`：`raw.Artist` struct（id/name/alias/img1v1Url/picUrl 等）+ `MapArtist` + `MapArtists`。新增（现状 Artist 嵌在 Song 里，没有独立实体）。
- `album.go`：`raw.Album` struct（id/name/picUrl/publishTime 等）+ `MapAlbum`。新增。
- `playlist.go`：`raw.Playlist` struct + `MapPlaylist`。从 model/playlist.go 迁移，**去掉 Platform 字段**（新架构单平台，不需要）。
- `user.go`：`raw.User` struct（userId/nickname/avatarUrl/followeds/follows 等）+ `MapUser`。新增（15 个接口里 LoginStatus/Recommend/FM 的返回含用户信息）。

### map 函数返回 proto 类型

map 函数返回 `gen/go` 生成的 `pb.*` 类型（如 `*pb.Song`），不是旧的 model 类型。proto message 在 issue 0001 已定义。这建立了 model 层与 proto 的依赖：model 包 import gen/go。

### 歌词特殊处理

`model/lyrics.go` 不作为复用实体（歌词结构单一，不跨接口复用），其映射逻辑直接放在歌词 endpoint 的 MapResponse 里。只提炼被多接口复用的 5 实体。

## Acceptance criteria

- [ ] `internal/netease/model/song.go`：raw.Song struct（网易云缩写字段镜像）+ MapSong + MapSongs
- [ ] `artist.go`：raw.Artist + MapArtist + MapArtists
- [ ] `album.go`：raw.Album + MapAlbum
- [ ] `playlist.go`：raw.Playlist + MapPlaylist（去 Platform 字段）
- [ ] `user.go`：raw.User + MapUser
- [ ] map 函数返回 gen/go 的 pb.* 类型
- [ ] 消除旧 model/ 与 provider.*Result 双套类型（旧类型在 issue 0005 删除）
- [ ] joinArtists/joinArtistsRaw 重复逻辑合并为 MapArtist
- [ ] 每个实体的 map 纯函数测试：网易云 JSON fixture → proto 响应字段正确
- [ ] 所有导出符号有 godoc 注释
