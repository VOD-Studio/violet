# Issue-0005：前端删补丁层 + http 拦截器改 401 直接踢

## Parent

PRD-0002（`../../prd/0002-登录态opaque-session重构.md`）

## What to build

删除为旧 JWT 掉登录打的所有前端补丁，简化 http 拦截器：401 = 直接踢重登，无 refresh、无挂起重放、无跨 tab 互斥。这是 opaque session 治本后前端能甩掉的复杂度。

## Acceptance criteria
- [ ] 删 `src/shared/api/auth-gate.ts`（authGate 的 requestReplay / flush / rejectAll / notifySessionExpired 全套）
- [ ] 删 `refresh-queue.ts`（跨 tab navigator.locks 互斥）
- [ ] 删 `src/widgets/AuthDebugPanel`
- [ ] 删主动刷新定时器（scheduleRefresh / `__retried` 标记逻辑）
- [ ] 删双链 401 重放（http.ts 拦截器里的 setReplayer / requestReplay 注入）
- [ ] http.ts 拦截器改：401 → `clearSessionActive()` + 触发 LoginDialog（保留会话失效提示），不挂起、不重放
- [ ] session.ts 保留 `clearSessionActive`（useMe enabled 仍需），去掉 refresh 相关
- [ ] 删除前端对 mimo_access / mimo_refresh cookie 的任何引用
- [ ] `pnpm typecheck && pnpm test` 全绿
