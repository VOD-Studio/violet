# Issue-0006：专辑与歌手接口

## Parent

PRD：`../../prd/0006-mimo-music-phase-2.md`（user stories 7-8；能力扩展）

## What to build

provider 实现 Album 和 Artist 两个能力，新增两个公开端点：`GET /api/v1/albums/:id`（专辑详情 + 含歌曲列表）、`GET /api/v1/artists/:id`（歌手信息 + 热门歌曲）。走 service 缓存编排（命中即返，未命中调 provider 写缓存），handler 暴露端点，OpenAPI 补 path 定义。这是博客播放器按专辑/歌手浏览的能力补充——Phase 1 只能按歌单和单曲查。

## Acceptance criteria

- [ ] `provider/netease/album.go`：Album 能力实现，Detail(ctx, albumID) → model.Album（含歌曲列表）
- [ ] `provider/netease/artist.go`：Artist 能力实现，Info(ctx, artistID) → 歌手信息 + 热门歌曲
- [ ] `service/album.go` + `service/artist.go`：缓存编排（先查缓存 → 未命中调 provider → 写缓存，TTL 24h）
- [ ] `GET /api/v1/albums/:id` 端点（handler + 路由注册）
- [ ] `GET /api/v1/artists/:id` 端点（handler + 路由注册）
- [ ] `openapi/paths/album.go` + `openapi/paths/artist.go`：path 定义补全
- [ ] service 层测试（mock provider + mock cache）：缓存命中/未命中分支
- [ ] 手动验证：用真实网易云专辑 ID 和歌手 ID，返回正确数据（需联网）
- [ ] 所有导出符号有 godoc 注释

## Blocked by

无 —— Phase 1 已完成，provider / service / handler 骨架可直接复用。
