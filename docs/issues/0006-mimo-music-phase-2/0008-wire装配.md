# Issue-0008：wire 装配

## Parent

PRD：`../../prd/0006-mimo-music-phase-2.md`（Implementation Decisions - wire 装配）

## What to build

引入 google/wire，在 `internal/bootstrap/` 建 provider set，server 和 worker 共享装配。把 main.go 里 Phase 1 / Phase 2 累积的手动 new 调用全部替换为 wire 生成的装配代码。组件多了之后手动装配维护成本高、容易漏注入，wire 在编译期保证依赖完整。这一步放在 Phase 2 末尾——前面切片（Redis / metrics / decorator / 能力扩展）落地后，组件集稳定再统一切换。

## Acceptance criteria

- [ ] `internal/bootstrap/wire.go`：provider set 定义（config / redis / cache / store / provider / decorator / services / handlers）
- [ ] `internal/bootstrap/wire_gen.go`：wire 生成的装配代码
- [ ] `make wire`（或 `wire ./...`）在 mimo-music 目录可用，可重新生成
- [ ] server main.go 用 wire 装配，移除手动 new 链
- [ ] worker main.go 用 wire 装配（取所需子集），移除手动 new 链
- [ ] server 和 worker 共享同一 bootstrap provider set，不重复定义
- [ ] `make build` / `make test` 编译通过，现有测试不回归
- [ ] 手动启动 server + worker，启动日志正常、依赖注入完整
- [ ] 所有导出符号有 godoc 注释

- Issue-0003（metrics，注入 metrics registry）
