# Issue-0007：推荐与私人 FM

## Parent

PRD：`../../prd/0006-mimo-music-phase-2.md`（user stories 9-10；能力扩展）

## What to build

provider 实现 Recommend 和 FM 两个能力（均需登录态），新增两个端点：`GET /api/v1/recommend/daily`（每日推荐歌曲）、`GET /api/v1/fm`（私人 FM）。service 编排走 Cookie 轮换取登录态注入 provider，结果按需缓存（推荐/FM 内容时效性强，TTL 短，如 1h）。handler 暴露端点，OpenAPI 补 path。这是博客"今日推荐"和"随机播放"的能力来源——必须登录才能拿到。

## Acceptance criteria

- [ ] `provider/netease/recommend.go`：Recommend 能力实现，Daily(ctx) → 每日推荐歌曲列表
- [ ] `provider/netease/fm.go`：FM 能力实现，Personal(ctx) → 私人 FM 歌曲
- [ ] `service/recommend.go` + `service/fm.go`：编排（取 Cookie 注入 → 调 provider → 短 TTL 缓存）
- [ ] `GET /api/v1/recommend/daily` 端点（handler + 路由注册）
- [ ] `GET /api/v1/fm` 端点（handler + 路由注册）
- [ ] 无可用 Cookie（所有 session 失效）时返回明确 401/503 错误，而非空数据
- [ ] `openapi/paths/recommend.go` + `openapi/paths/fm.go`：path 定义补全
- [ ] 手动验证：登录后两个端点返回真实推荐 / FM 数据（需联网 + 有效 Cookie）
- [ ] 所有导出符号有 godoc 注释

## Blocked by

- Issue-0005（Cookie 轮换，推荐/FM 依赖登录态轮换取可用 Cookie）
