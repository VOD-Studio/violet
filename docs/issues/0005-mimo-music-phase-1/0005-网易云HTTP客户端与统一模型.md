# Issue-0005：网易云 HTTP 客户端 + model + errors + converter

## Parent

PRD：`../../prd/0005-mimo-music-phase-1.md`
架构：`../../adr/mimo-music-architecture.md`（第 3、4、7 节）

## What to build

在加密层之上构建网易云 HTTP 客户端，能够发送加密请求到网易云端点并解析响应。同时建立统一 model（跨平台 DTO）、统一 errors、以及网易云原始结构到 model 的 converter。

这一步建立 Provider 接口和 Registry，但不实现具体业务能力（登录、歌单等留给后续 issue）。客户端能发出一个最简单的请求（如 `/song/detail`）并返回 model 类型，证明加密 + 请求 + 转换管道通。
