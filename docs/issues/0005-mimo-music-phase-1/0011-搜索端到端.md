# Issue-0011：搜索端到端

## Parent

PRD：`../../prd/0005-mimo-music-phase-1.md`（user stories 13-14）

## What to build

实现歌曲搜索的完整垂直切片：provider 调用网易云搜索接口 → service 缓存编排 → handler 暴露 HTTP 端点 → OpenAPI 文档。支持关键词搜索 + 结果数量限制。

搜索结果缓存 TTL 短（10 分钟），热门关键词不反复打上游。

## Acceptance criteria

- [ ] `mimo-music/provider/netease/search.go`：Search 能力实现
  - Search(ctx, keyword, limit) → []model.Song
- [ ] `mimo-music/service/search.go`：搜索编排
  - Search：缓存 10min（key 含 keyword + limit）
  - 从 store 取 Cookie 注入 provider（可选）
- [ ] `mimo-music/internal/server/handler/search.go`：`GET /api/v1/search?q=&limit=` 端点
- [ ] `mimo-music/openapi/paths/search.go`：搜索端点 path 定义
- [ ] service 层测试（mock provider + mock cache）：
  - 缓存 key 包含 keyword 和 limit
  - 缓存命中时不调 provider
  - limit 参数边界值处理
- [ ] 手动验证：搜索真实关键词返回结果
- [ ] 所有导出符号有 godoc 注释
