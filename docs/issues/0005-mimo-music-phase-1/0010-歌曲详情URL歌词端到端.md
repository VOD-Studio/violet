# Issue-0010：歌曲详情 / 播放URL / 歌词端到端

## Parent

PRD：`../../prd/0005-mimo-music-phase-1.md`（user stories 9-12）

## What to build

实现歌曲相关能力的完整垂直切片：歌曲详情、播放 URL（含音质选择）、歌词。三个能力共享 provider/song.go 和 service/song.go，但各有独立的缓存 TTL 策略。

播放 URL 是播放器的核心——拿到 URL 才能真正播放音频。URL 有时效性，缓存 TTL 短（30 分钟）。歌词内容稳定，缓存 TTL 长（24 小时）。

## Acceptance criteria

- [ ] `mimo-music/provider/netease/song.go`：Song 能力实现
  - Detail(ctx, songID) → model.Song
  - URL(ctx, songID, level) → 播放直链（level: standard / exhigh / lossless）
  - Lyric(ctx, songID) → model.Lyrics
- [ ] `mimo-music/service/song.go`：歌曲编排
  - Detail：缓存 24h
  - URL：缓存 30min（短 TTL，URL 会过期）
  - Lyric：缓存 24h
  - 从 store 取 Cookie 注入 provider（播放 URL 需登录态拿非试听）
- [ ] `mimo-music/internal/server/handler/song.go`：3 个端点
  - `GET /api/v1/songs/:id` —— 歌曲详情
  - `GET /api/v1/songs/:id/url?level=` —— 播放 URL
  - `GET /api/v1/songs/:id/lyric` —— 歌词
- [ ] `mimo-music/openapi/paths/song.go`：3 个端点 path 定义
- [ ] service 层测试（mock provider + mock cache）：
  - URL 缓存 TTL 为短（验证 Set 时传了 30min）
  - 歌词缓存 TTL 为长（验证 Set 时传了 24h）
  - provider 返回空 URL 时 service 的处理
- [ ] 手动验证：用真实歌曲 ID，播放 URL 可播放、歌词可获取
- [ ] 所有导出符号有 godoc 注释
