# Issue-0002：可观测性基础设施

## Parent

PRD：`../../prd/0005-mimo-music-phase-1.md`

## What to build

建立完整的可观测性基础设施，供后续所有业务切片使用。包括 slog 日志（JSON/text 切换 + 动态等级）、OTel 最小初始化（noop exporter，只为生成 trace_id 供日志关联）、敏感字段脱敏 handler、统一字段名常量、高频采样 handler。

HTTP 访问日志中间件自动记录每个请求（method / path / status / duration_ms / request_id / trace_id）。所有日志只写 stdout，不落盘。

核心层（provider/）通过 Logger 接口解耦，不直接依赖 slog。运行时层注入 slog adapter。

- [ ] `mimo-music/observability/logger.go`：slog.LevelVar 动态等级，支持 SIGHUP 信号调级
