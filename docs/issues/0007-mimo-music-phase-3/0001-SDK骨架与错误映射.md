# Issue-0001：SDK 骨架与错误映射

## Parent

PRD：`../../prd/0007-mimo-music-phase-3.md`（user stories 1、2、4；Implementation Decisions - SDK 包）

## What to build

建 `pkg/mimomusic/` Go 包，作为 mimo-music 的官方 HTTP client SDK，让外部调用方 import 后直接调用全量端点，不必手写 HTTP。本切片只落骨架：HTTP client 构造（base URL + Option 模式）、统一错误映射、重试与 context 支持，具体端点方法留待 0002/0003 各能力切片填充。

client 构造传入 base URL 与 `WithHTTPClient` / `WithTimeout` / `WithRetry` 等 Option；内部 transport 自带指数退避重试（复用 provider 包的 `IsRetryable` 判断或独立实现等价逻辑）；所有请求方法接收 `context.Context` 支持超时与取消。错误层建 `pkg/mimomusic/errors.go`：把 mimo-music HTTP 统一信封 `{code, data, message}` 里的业务 code 映射到 client 层的 Go error（哨兵 error + `errors.Is/As` 可判定），网络层错误（超时、连接拒绝）单独归类，避免上层用字符串判断。

这是 Phase 3 的入口切片——骨架就绪后 0002/0003 才有 client 可挂方法。SDK 包不得 import mimo-music 内部包，只依赖 model 包的 DTO 与 errors。

## Acceptance criteria

- [x] `pkg/mimomusic/client.go`：`NewClient(baseURL string, opts ...Option) *Client` 构造，`Option` 模式含 `WithHTTPClient` / `WithTimeout` / `WithRetry`
- [x] 所有请求方法（哪怕本切片只有一个健康检查示例方法）接收 `context.Context` 作为首参
- [x] 指数退避重试：可重试错误（5xx、网络超时）按配置次数重试，4xx 不重试
- [x] `pkg/mimomusic/errors.go`：HTTP 信封业务 code → 哨兵 error 映射，覆盖成功 / 未授权 / 限流 / 未找到 / 上游不可用 / 不支持的平台
- [x] 网络层错误（超时、连接拒绝）归类为可判定 error，不与业务 error 混
- [x] httptest.Server 单测：成功响应、各业务错误码、重试触发、超时
- [x] `pkg/mimomusic` 不 import `internal/` 任何包，只依赖 mimo-music 的 `model` 与 `errors`
- [x] 所有导出符号有 godoc 注释

## Blocked by

无 —— Phase 1/2 已完成，可立即开始。是 Phase 3 的入口切片。
