# Issue-0002：收藏与全站右键菜单

## Parent

PRD-0020（`../../prd/0020-自定义表情与收藏.md`）

## What to build

用户能右键点击别人在评论/推文/聊天里发出的、自己还没有的自定义表情，一键收藏进自己的表情库并立即可选用发送；已收藏的表情右键可移出，自己的表情右键可删除。系统表情和非表情内容的右键行为不受影响（浏览器原生菜单）。

## Acceptance criteria

### 权限与领域（收藏关系）

- [ ] `application/customemoji.Service` 新增 `Favorite`/`Unfavorite`：写读 `custom_emoji_favorites`（表已在 Issue-0001 建好）；`Favorite` 拒绝"收藏自己的表情"（无意义操作），拒绝超份额（owned+favorited 合计）
- [ ] `ResolveByIDs` 补齐 `favorited` 分支（viewer 收藏了该 ID 但非 owner 时返回 `relation=favorited`）
- [ ] 单测：收藏自己的表情报错；收藏后份额计数按 owned+favorited 合计；超份额拒绝；移出后 `ResolveByIDs` 回落到 `none`

### API

- [ ] `POST /custom-emojis/{id}/favorite`、`DELETE /custom-emojis/{id}/favorite`，均挂 SessionAuth
- [ ] handler 集成测试覆盖成功/收藏自己/超份额三条路径

### 前端：ContextMenu 原语

- [ ] 新增 `web/src/shared/ui/base/context-menu.tsx`，照 `dropdown-menu.tsx` 的 radix-ui 封装约定
- [ ] `web/src/providers.tsx` 的 `AppProvider` 挂一层全局 `ContextMenuTrigger`，覆盖 `{children}` 全部子树
- [ ] 菜单内容按右键目标动态决定：目标 `<img>` 带 `data-custom-emoji-id` 属性时才弹出自定义菜单，否则不 `preventDefault`（原生菜单直接生效）
- [ ] `EmojiText.tsx`/`ChatMessageContent.tsx`（及其对应渲染路径）渲染自定义表情 `<img>` 时附加 `data-custom-emoji-id` 与 relation 相关的 data 属性（系统表情不附加）
- [ ] 菜单项按 relation 三态：`none` → "收藏到我的表情"；`favorited` → "移出我的表情"；`owned` → "删除表情"

### 前端：EmojiPicker 收藏分组

- [ ] "我的表情" tab 新增"收藏来的"分组（Issue-0001 里恒空），展示 `GET /custom-emojis/mine` 的 `favorited` 数组
- [ ] `Emoji` 前端读模型补 `relation?: "owned" | "favorited"` 字段

### 测试

- [ ] 组件测试：右键系统表情/非表情内容不弹出自定义菜单；右键自定义表情按 relation 三态渲染对应菜单项；点击"收藏到我的表情"后触发正确的 API 调用与选择器数据刷新

## Blocked by

Issue-0001（需要 `CustomEmoji` 聚合、`custom_emoji_favorites` 表、resolver 骨架、EmojiPicker 基础 tab 与 `data-custom-emoji-id` 渲染属性已存在）。
