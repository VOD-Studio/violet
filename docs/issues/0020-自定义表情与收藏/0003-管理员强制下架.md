# Issue-0003：管理员强制下架

## Parent

PRD-0020（`../../prd/0020-自定义表情与收藏.md`）

## What to build

持有权限的管理员能强制下架任意用户的违规自定义表情，不限于自己上传的。下架后原上传者与全部收藏者同步失去选用权，已发出的历史消息/评论/推文中的引用降级为占位文本，不报错、不留死链接。

## Acceptance criteria

### 权限点

- [ ] `domain/permission` 新增 `CustomEmojiManage = MustParse("customemoji:manage")`（"管理自定义表情"）
- [ ] 迁移种子：插入 `customemoji:manage` 权限并授予 admin 角色，对齐 `083_create_chat.up.sql` 里 `chat:manage` 的种子方式
- [ ] 对应 `.down.sql` 撤销授权与权限行

### API 与应用层

- [ ] `DELETE /custom-emojis/{id}` 放开 `actor != owner` 分支：要求 `customemoji:manage`，否则 403；`actor == owner` 分支行为不变（Issue-0001 已实现）
- [ ] 集成测试：非 owner 无权限 → 403；非 owner 有 `customemoji:manage` → 成功下架

### 级联验证

- [ ] 下架后原上传者的"我的表情" tab 不再展示该表情
- [ ] 下架后全部收藏者的"我的表情" tab 不再展示该表情（收藏关联行可保留或清理，任一实现均可，只要读路径不再返回）
- [ ] 已发出的历史消息/评论/推文重新渲染时，该表情的 token 降级显示原始占位文本（验证 `ResolveByIDs` 对已下架 ID 返回未命中，前端兜底逻辑生效，不需要新增前端代码）
- [ ] 端到端/集成测试覆盖：创建 → 收藏 → 下架 → 断言原上传者与收藏者均查不到、历史内容渲染降级

## Blocked by

Issue-0001、Issue-0002（级联失效的验收需要收藏机制已存在）。
