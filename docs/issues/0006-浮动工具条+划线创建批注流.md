# Issue-0006：浮动工具条 + 划线创建批注流

## Parent

PRD-0001（`docs/prd/0001-锚点批注评论.md`）

## What to build

文章详情页的「创建侧」批注体验：用户选中正文任意连续文本（单块内）→ 浮动工具条出现 → 点击「划线批注」→ 右侧侧边栏展开空白卡片（选中原文为引言）→ 写 → 提交 → 高亮落定 + 「审批中」徽章。这是高频路径，要求零跳转、所见即所得。

端到端行为：
- 已登录用户在正文选中文本（`mouseup` / `selectionchange`）→ 选区上方浮现 `FloatingToolbar`（neon 描边 + `bg-surface-glass` 毛玻璃 + 「划线批注」按钮 + 几个快捷 emoji）。
- 工具条用 Issue-0004 的 `range-to-anchor.ts` 判定：单块内 → 启用「划线批注」；跨块 → 按钮置灰 + tooltip「请在同一段落内选择」。
- 点击「划线批注」→ 右侧栏（Issue-0005 的 `AnnotationSidebar`）就地展开空白卡片：选中原文作为引言区展示 + 输入框 focus。
- 提交 → 调 `useCreateComment`（带 anchor 五元组）→ onSuccess 高亮落定（走 Issue-0005 的 AnnotationLayer 重渲染）+ 卡片转 pending 态 + 「审批中」徽章。
- 工具条快捷 emoji：直接给选中段落加 emoji 反应（调 `useAddReaction`，但这需要先有一条评论——本期约定快捷 emoji 仅在「该块已有批注」时启用，否则提示「先写一条批注」；纯反应无评论的场景留待后续）。
- 未登录用户选中：工具条按钮文案变「登录后批注」，点击触发 `login-dialog-store.open()`。
- `prefers-reduced-motion`：工具条出现/消失降级为静态显隐。

## Acceptance criteria

- [ ] `FloatingToolbar` 组件：监听选区，定位在选区上方（计算 Selection boundingRect）；选区消失时隐藏。
- [ ] 工具条视觉：neon 描边 + `bg-surface-glass` 毛玻璃 + 「划线批注」按钮 + 快捷 emoji 区。
- [ ] 单块判定接 Issue-0004 的 `range-to-anchor.ts`：跨块时按钮置灰 + tooltip；空选区/选区在非内容区（如代码块外）不显示工具条。
- [ ] 点击「划线批注」→ `AnnotationSidebar` 展开空白卡片（选中原文引言 + 输入框 focus），零跳转。
- [ ] 提交流：调 `useCreateComment({ body, anchor })`；onSuccess invalidate `commentKeys.lists()`；高亮 + 卡片落定 + pending 徽章。
- [ ] 未登录态：按钮变「登录后批注」，点击调 `useLoginDialogStore().open()`（复用现有 store）；不直接调 API。
- [ ] 快捷 emoji：仅在选中块已有批注时启用（避免无评论的悬挂反应）；否则置灰提示。
- [ ] 工具条定位防抖（selectionchange 高频触发）；滚动/resize 时重新定位或隐藏。
- [ ] `prefers-reduced-motion` 降级静态显隐。
- [ ] 测试：
  - `FloatingToolbar` 单块/跨块/未登录三态（RTL render + mock Selection）。
  - 点击「划线批注」触发 sidebar 展开回调（vi.fn）。
  - 提交后 pending 徽章出现（接 Issue-0002 的 PendingBadge）。
  - 注：jsdom Selection 支持有限，需 polyfill 桩或抽象出可测的事件处理函数。
