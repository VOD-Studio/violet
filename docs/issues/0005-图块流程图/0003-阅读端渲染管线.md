# Issue-0003：阅读端渲染管线（tracer bullet）

## Parent

PRD：`../../prd/0005-图块流程图.md`

## What to build

打通阅读端：content_html 含 `<div data-type="diagram-block" data-format data-source>` 时，阅读端识别 → 调 #1 的 `renderMermaid` → 写入 ref 容器。同时把当前散落在 `markdownComponents`（span/div/pre/code 四个 if 分支）的分发逻辑升级为真正的 `format → 渲染器` 注册表抽象，收敛后续多格式扩展点。mermaid 依赖走 `React.lazy` 仅在含图块文章时加载，主题切换时重新 initialize + 重渲染所有可见图块。

## Acceptance criteria

- [ ] `HtmlContent.tsx` 的 hast sanitize schema 白名单追加：`div` 节点放行 `dataFormat` / `dataSource` 属性（hast-util-sanitize 用 camelCase 属性名）
- [ ] 新建渲染器注册表 `web/src/shared/ui/diagram/renderers.ts`：`{ [format: string]: { ReaderComponent: React.LazyExoticComponent, sanitizeAttrs: string[] } }`，首期注册 `mermaid` 一项
- [ ] `markdown-components.tsx` 的 `div` 分支改用注册表分发：`data-type === "diagram-block"` 时按 `data-format` 查注册表 → lazy 渲染对应组件；未知 format → 降级显示 source 文本
- [ ] 新增 `DiagramBlock` lazy 组件（`React.lazy`）：props `{ format, source }` → 持 ref 容器 → `useEffect` 调 `renderMermaid(source, currentTheme)` → 清理后 SVG 写入 `ref.current.innerHTML`
- [ ] mermaid 仅通过 `DiagramBlock` 的 lazy 链路加载，不含图块的文章页不拉 mermaid chunk
- [ ] 主题跟随：监听 `next-themes` 的 `resolvedTheme`（或 `<html>.classList` MutationObserver），主题变 → 重新 `renderMermaid` 重渲染
- [ ] 容器样式：居中 + `overflow-x-auto`（宽图横向滚动，不缩放变形）
- [ ] 错误降级：`renderMermaid` 返回 error 时显示「图表渲染失败」占位 + 折叠的源码（不向读者暴露详细错误）
- [ ] 无 JS 环境：data-source 作为文本内容降级显示（mermaid 源本身可读）
- [ ] 复用现有 `HtmlContent.test.tsx` seam 加测试：含 `div[data-type=diagram-block][data-format=mermaid][data-source]` 的 HTML → 属性经白名单保留
- [ ] `make web-typecheck && make web-lint` 全绿
- [ ] 手动验证：含图块文章渲染出 SVG；切换站点明暗主题 → 图块重渲染换色；无图块文章的 network 面板无 mermaid chunk 请求

- hast 白名单位置：`web/src/shared/ui/markdown-preview/HtmlContent.tsx` 内 sanitize schema（现有 `span/div` 放行 `dataType/dataLatex`、`pre` 放行 `dataRunnable/dataLang/dataOverrides/dataSource` 的同款）
- 分发现状：`web/src/shared/ui/markdown-preview/components/markdown-components.tsx` 的 `span` 分支判 `data-type === "inline-math"`、`div` 分支判 `data-type === "block-math"`、`pre` 分支判 `data-runnable === "true"` —— 本 issue 把 diagramBlock 的 div 分支接入注册表，现有 inline-math/block-math 可暂留 if（不强制重构），重点是新格式走注册表

- lazy 模式参照 `markdown-components.tsx` 现有 `React.lazy(() => import('../../katex/MathFormula'))` 与 FencedCodeBlock（shiki）的同款
- 主题监听参照 `web/src/shared/ui/theme-transition.tsx` 与 `particle-field.tsx`（MutationObserver 监听 `<html>.classList` 的先例）
