# Issue-0002：编辑器节点与输入入口（tracer bullet）

## Parent

PRD：`../../prd/0005-图块流程图.md`

## What to build

新建独立 TipTap atom 节点 `diagramBlock`（`format` + `source` 属性），打通 ` ```mermaid ` 围栏块的双向 Markdown 序列化与 slash 菜单插入。参照官方 `@tiptap/extension-mathematics` 的 BlockMath 节点模式（schema + markdownTokenizer + parseMarkdown + renderMarkdown 四件套），但**不复用** codeBlock 分流——diagramBlock 是独立 atom，source 不进 contentEditable。

本期不实现弹层编辑（图块在文档内显示为占位或最小渲染，编辑交互留给 Issue-0004）。重点是把节点 schema、围栏往返、content_html 载体产出打通。

## Acceptance criteria

- [ ] 新增 `diagramBlock` TipTap Node：`group: block`、`atom: true`、属性 `format`（string，default `"mermaid"`）+ `source`（string，default `""`）
- [ ] `addAttributes()`：`format` 的 `parseHTML: el => el.getAttribute("data-format")`、`renderHTML: attrs => ({ "data-format": attrs.format })`；`source` 同理用 `data-source`
- [ ] `parseHTML()`：tag 选择器 `div[data-type="diagram-block"]`
- [ ] `renderHTML()`：输出 `<div data-type="diagram-block" data-format="..." data-source="...">`
- [ ] Markdown 围栏双向序列化：`markdownTokenizer`（block level，识别 ` ```mermaid ` fence）+ `parseMarkdown`（token → `{ type: "diagramBlock", attrs: { format: "mermaid", source: token.text } }`）+ `renderMarkdown`（node → ` ```mermaid\n${source}\n``` `）
- [ ] 未知 info string 的围栏块仍走原 codeBlock 路径（`python` 等不被劫持）
- [ ] slash 菜单加「插入流程图」命令（参照现有 slash-items 的可运行代码块命令形态）
- [ ] 编辑器 `extensions/index.ts` 注册 diagramBlock
- [ ] `make web-typecheck && make web-lint` 全绿
- [ ] 手动验证：编辑器输入 ` ```mermaid\ngraph LR; A-->B\n``` ` → 识别为 diagramBlock 节点；`editor.getMarkdown()` 回写为同形态围栏；保存后 content_html 含 `<div data-type="diagram-block" data-format="mermaid" data-source="...">`

## 实现指引

- 完整套用官方 `@tiptap/extension-mathematics` 的 BlockMath 结构（`web/node_modules/@tiptap/extension-mathematics/dist/index.js` 是范本），只是 schema 属性从 `latex` 换成 `format` + `source`、tokenizer 正则从 `^\$\$...` 换成 fence 规则
- 项目侧参照 `web/src/features/editor/ui/MathView.tsx` 的「瘦适配器」入口模式（`createMathExtensions()` 那样的工厂函数），但本 issue 暂不挂 NodeView（占位即可，Issue-0004 接入弹层）
- 围栏 fence 解析参照 `@tiptap/extension-code-block` 的 `markdownTokenName: 'code'` + `parseMarkdown(token)` 读 `token.lang` 的机制
- slash 命令参照 `web/src/features/editor/slash-menu/slash-items.ts` 里「可运行代码块」命令（约 145-161 行）的 `insertContent({type:'codeBlock', attrs:{...}})` 形态
- 本 issue 不做节点级单测（沿用数学公式先例，靠手动验证围栏往返）
