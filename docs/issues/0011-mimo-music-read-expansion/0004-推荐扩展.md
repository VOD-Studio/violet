# Issue-0004：推荐扩展（深化 RecommendService，排除 MV/电台/节目）

## Parent

PRD：`../../prd/0011-mimo-music-read-expansion.md`（user stories 27-29；Implementation Decisions）
前置：地基阶段完成（RecommendService 已存在，含 GetDailyRecommend 歌曲）

## What to build

在 `RecommendService` 上扩展推荐能力，**只做返回 Playlist/Song 的推荐**。排除：推荐 MV（#46）、推荐视频（#151）→ MV/视频 Context；推荐电台（#49）、推荐节目（#50）→ FM/电台 Context。

3 个接口：

- 每日推荐歌单（#36）：需登录态，返回 `repeated Playlist`，TTL 1h（每日变化）。
- 推荐歌单（#47）：匿名，返回 `repeated Playlist`，TTL 1h。
- 推荐新音乐（#48）：匿名，返回 `repeated Song`，TTL 1h。

`MapResponse` 调 `model.MapPlaylists` / `model.MapSongs` 复用。每日推荐歌单 `Auth=AuthLoggedIn`（个性化），其余 `Auth=AuthAnonymous`。

改动链路同其他 issue。列表响应用完整实体（遵循 ADR）。

## Acceptance criteria

- [x] `proto recommend.proto` 的 RecommendService 加 3 个 rpc + message
- [x] 3 个 endpoint 声明，每日推荐歌单 AuthLoggedIn + 不缓存，其余 AuthAnonymous + TTL 1h
- [x] service 3 个方法恒一行（DailyRecommendPlaylists 走 executeOverride，其余 Execute）
- [x] endpoint MapRequest/MapResponse 纯函数测试（extend_test.go）
- [x] `make proto` 生成成功
- [x] 所有导出符号有 godoc / proto 注释

## 实现备注

- **DailyRecommendPlaylists 不缓存**：per-user 个性化结果（每日推荐歌单按登录用户生成），走 executeOverride + cookie override，不缓存（与 song.IsLike / album.SubscribedAlbums 同理）。
- **RecommendNewSongs 嵌套结构**：网易云 `/personalized/newsong` 把歌曲嵌在 `result[i].song` 下（非扁平），model.DecodeRecommendNewSongs 解嵌套后复用 MapSong。
- **RecommendPlaylists 路径**：用模块源码的 `/api/personalized/playlist`（而非文档的 `/personalized`），是实际数据端点。
- **排除**：推荐 MV（#46）/推荐视频（#151）→ MV/视频 Context；推荐电台（#49）/推荐节目（#50）→ FM/电台 Context。

## Blocked by
