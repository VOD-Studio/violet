# Issue-0002：专辑扩展（深化 AlbumService，排除数字专辑）

## Parent

PRD：`../../prd/0011-mimo-music-read-expansion.md`（user stories 15-21；Implementation Decisions）
前置：地基阶段完成（AlbumService 已存在）、cookie 重构完成（PRD 0010）

## What to build

在 `AlbumService` 上扩展普通专辑的查询与收藏能力。**只做普通专辑**——数字专辑（购买/销量/榜单/语种馆，9 个）归数字专辑 Context，不在本 issue。

7 个接口：

- 新碟上架（#43）、最新专辑（#93）、全部新碟（#159）：分页列表，返回 `repeated Album`，复用 `model.MapAlbum`。
- 已收藏专辑列表（#96）：需登录态，返回 `repeated Album`。
- 专辑动态信息（#121）：返回 Album 的动态更新字段。
- 专辑歌曲音质（#280）：返回专辑内歌曲可选音质。
- 收藏/取消收藏专辑（#120）：写操作（toggle），`executeOverride`，返回 `{subscribed}`。

改动链路同歌曲扩展。列表接口遵循列表响应统一实体 ADR（用完整 Album，不建精简 DTO）。

## 实现备注

- **#43 新碟上架 vs #159 全部新碟**：两者是不同端点。#43 = `/top/album`（`top_album.js`，实际请求 `/api/discovery/new/albums/area`，带 area/year/month/type 榜单式过滤）；#159 = `/album/new`（`album_new.js`，分页 + area）。
- **#93 最新专辑** = `/album/newest`（`album_newest.js`，`/api/discovery/newAlbum`，首页新碟）。
- **#280 专辑歌曲音质** = eapi（`/api/album/privilege` 默认 crypto=eapi），复用 Step 0 的 eapi engine 修复。
- **#120 收藏 toggle**：网易云用 path 区分 sub/unsub，拆成 Subscribe/Unsubscribe 两端点（path 是 Meta 固定字段），service 按请求 subscribe 标志分派。
- **SubscribedAlbums 不缓存**：per-user 结果，cookie 不透明无法派生稳定 cache key（与 song.IsLike 同理，code-review 反馈）。
- **AlbumDynamic.isSub 注意**：响应含 per-user 的 isSub 字段，但端点走匿名 session + 缓存（计数信息为主用途）；调用方需准确收藏态应另调 SubscribeAlbum。
