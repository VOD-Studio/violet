# Issue-0002：前端底部自由评论区

## Parent

PRD-0001（`docs/prd/0001-锚点批注评论.md`）

## What to build

文章详情页底部新增传统自由评论区，承载与正文无强位置关联的总体讨论（即 `anchor` 为空的顶级评论 + 其嵌套回复）。复用现有 `useComments` / `useCreateComment` / 反应 hooks（Issue-0001 改造后的契约）。**底部评论允许匿名**（昵称 + 邮箱），登录用户也可用。

端到端行为：
- 文章详情页 `</article>` 之后渲染评论区。
- **匿名用户**：填昵称 + 邮箱即可写评论；提交后展示「已提交，待管理员审核」一次性 toast（匿名无会话，无 pending 徽章）。
- **登录用户**：作者信息自动从会话填充，提交后立即看到带「审批中」徽章的自己刚提交的 pending 评论。
- 评论卡片支持嵌套回复（最大深度 4，沿用现有 path+depth）、emoji 反应（幂等、可撤销，匿名按 ip_hash、登录按 user_id）。
- 视觉沿用 `AnnouncementCard` 票据美学：font-mono + SpotlightCard 外壳 + border-edge-hairline + neon severity 配色 + 「审批中」徽章。
- 写评论入口始终可见（不强制登录），与「划线批注需登录」的边界区分清楚。

本 issue **不**做正文批注（Issue-0005/0006）、不碰右侧栏。本 issue 内的组件均在 `features/comments/ui/` 内，**按职责分组提交**，不每个组件单独拆 commit（遵循 AGENTS.md 第 1 条「公共组件单独提交」——feature 内部组件按职责分组）。
