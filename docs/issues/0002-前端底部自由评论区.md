# Issue-0002：前端底部自由评论区

## Parent

PRD-0001（`docs/prd/0001-锚点批注评论.md`）

## What to build

文章详情页底部新增传统自由评论区，承载与正文无强位置关联的总体讨论（即 `anchor` 为空的顶级评论 + 其嵌套回复）。复用现有 `useComments` / `useCreateComment` / 反应 hooks（Issue-0001 改造后的契约）。**底部评论支持匿名（留言板模式）和登录两种**。

端到端行为：
- 文章详情页 `</article>` 之后渲染评论区。
- **匿名用户（留言板模式）**：
  - 评论区显示「登录后查看 N 条评论」引导（黑洞模式，看不到任何评论，含自己刚提交的）。
  - 留言入口：填昵称 + 邮箱 → 点「发送验证码」（调 `POST /comments/code`）→ 邮箱收到 6 位码 → 填码 + 留言内容 → 提交。
  - 提交后展示「已提交，管理员审核通过后登录可见」一次性 toast（看不到自己刚提交的）。
  - 已留过言（409）→ 提示「该文章下你已留过言」。
- **登录用户**：
  - 作者信息自动从会话填充，看到所有 approved 评论 + 自己 pending（带「审批中」徽章）。
  - 可嵌套回复、emoji 反应（最大深度 4，幂等）。
- 视觉沿用 `AnnouncementCard` 票据美学：font-mono + SpotlightCard 外壳 + border-edge-hairline + neon severity 配色 + 「审批中」徽章。
- 登录引导：匿名评论区顶部有「登录参与完整讨论」按钮（复用 `login-dialog-store`）。

本 issue **不**做正文批注（Issue-0005/0006）、不碰右侧栏。本 issue 内的组件均在 `features/comments/ui/` 内，**按职责分组提交**，不每个组件单独拆 commit（遵循 AGENTS.md 第 1 条「公共组件单独提交」——feature 内部组件按职责分组）。

## Acceptance criteria

- [ ] `web/src/routes/blog/$slug.tsx` 的 loader 在现有文章详情 `ensureQueryData` 之后追加 `ensureQueryData(comments list)`，首屏全量预取、SSR 友好无闪烁。
- [ ] 渲染区在 `</article>` 之后插入底部评论区（仅渲染 `anchor` 为空的顶级评论 + 其回复树；`anchor` 非空的留待 Issue-0005）。
- [ ] 实现 `features/comments/ui/` 内的组件（feature 内部，按职责分组提交）：
  - `CommentSection`（底部评论区主容器；**匿名 viewer 显示「登录后查看 N 条评论」引导 + 留言入口，不渲染评论列表**；登录 viewer 渲染完整列表）
  - `CommentCard`（单条评论卡片，含 severity 配色、作者徽章、「审批中」PendingBadge、回复展开）
  - `CommentForm`（输入框 + emoji 选择器；**双模式**）：
    - 登录态：从会话取作者信息、隐藏昵称邮箱、无验证码；提交后 pending 徽章。
    - 匿名态：昵称 + 邮箱 + **「发送验证码」按钮 + 验证码输入框**（两步流）；提交后 toast「已提交，管理员审核通过后登录可见」。
  - `ReactionBar`（emoji 反应条，调用 `useAddReaction` / `useRemoveReaction`，幂等；**仅登录用户可见/可操作**，匿名不渲染）
  - `PendingBadge`（「审批中」徽章，仅在 `status==='pending'` 渲染）
- [ ] 新增 `useSendCommentCode` mutation（调 `POST /posts/{postId}/comments/code`）：发送验证码按钮带 60s 倒计时（防重复点），失败 toast。
- [ ] 匿名 CommentForm 两步流：填邮箱 → 发码（按钮倒计时）→ 填码 + 留言 → 提交（`useCreateComment` 带 `code` 字段）。
- [ ] 提交评论调用 `useCreateComment`（已存在），onSuccess 走 queryClient invalidate；登录提交者本人立即看到 pending + 「审批中」徽章；匿名提交者看到 toast（黑洞模式，不刷新出自己评论）。
- [ ] 409（已留过言）→ toast「该文章下你已留过言」+ 禁用留言表单。
- [ ] 匿名评论区顶部「登录参与完整讨论」按钮，点击调 `useLoginDialogStore().open()`。
- [ ] 嵌套回复以缩进对话树展示，最大深度 4（后端已强制）；**回复入口仅登录用户可见**（匿名看不到评论，逻辑自洽）。
- [ ] 视觉：font-mono + SpotlightCard（react-bits）外壳 + 1px neon 色条 + border-edge-hairline；`prefers-reduced-motion` 下降级静态。
- [ ] 加载阶段用 `shared/ui/shimmer-skeleton`，无空白闪烁。
- [ ] `entities/comment/model/types.ts` 的 `Comment` 类型新增 `status: CommentStatus` 字段；`features/comments/model/types.ts` 的 `CreateComment` 新增 `code?: string`（匿名必填）；新增 `SendCommentCode` 类型 `{ email: string }`（与 Issue-0001 后端契约同步）。
- [ ] 前端测试（不挂真实 QueryClient，全仓约定）：
