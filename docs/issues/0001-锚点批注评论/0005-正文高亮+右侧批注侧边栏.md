# Issue-0005：正文高亮 + 右侧批注侧边栏（双侧信息层 + 滚动联动）

## Parent

PRD-0001（`../../prd/0001-锚点批注评论.md`）

## What to build

文章详情页的「消费侧」批注体验：把已存在的批注（`anchor` 非空的 approved 评论）渲染到正文高亮 + 右侧 sticky 侧边栏，形成与左侧 `ArticleToc` 对称的「双侧信息层」。**本 issue 不含创建流**（Slice 6）——可先用 mock 一条带 anchor 的评论验证渲染，等 Slice 6 接通真实创建。

端到端行为：
- 桌面 2xl+：正文区外包 `AnnotationLayer` 渲染所有批注高亮；右侧 grid 区插入 `AnnotationSidebar`（sticky）；左侧 `ArticleToc` 不变 → 三栏布局。
- 正文滚动到某条高亮 → 右侧对应卡片亮起 neon 边框（IntersectionObserver）。
- 点击右侧卡片 → 正文滚动到对应高亮（scrollIntoView）。
- 高亮 severity→neon 配色（Issue-0004 的 `severity.ts`）：未回复 cyan / 有回复 pink / 作者本人 green（作者判定 Issue-0001 后端给 `is_author`，本期前端读取）。
- 小屏（lg 以下）：不渲染右侧栏；点击高亮弹 `AnnotationInlineBubble` 行内气泡。
- a11y：键盘 Tab 可聚焦高亮、Enter 打开对应卡片；`prefers-reduced-motion` 降级静态；aria 关联（高亮 `aria-describedby` → 卡片，卡片 `aria-labelledby` → 高亮）。
- 加载阶段：shimmer skeleton 占位。
