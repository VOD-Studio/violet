# Issue-0004：前端锚点算法库（block-id / range-to-anchor / relocate / severity）

## Parent

PRD-0001（`../../prd/0001-锚点批注评论.md`）

## What to build

实现评论 feature 内部的前端算法库，为 Slice 5（正文高亮 + 侧边栏）和 Slice 6（划线创建）提供纯逻辑支撑。**prefactor issue，本身不产生用户可见 UI**，但每个算法都有穷尽单测覆盖。

四个模块（均在 `web/src/features/comments/lib/`，feature 内部，与对应 UI 接入合并提交即可，**不单独拆 commit**——除非被 comments 之外的 feature 引用，遵循 AGENTS.md 第 1 条）：

1. **`block-id.ts`** —— `computeBlockId(element: HTMLElement): string`：取块级元素（`<p>` / `<h2>` / `<li>` / `<pre>`）的纯文本，SHA1 前 8 位。要求跨 SSR/客户端渲染一致、跨同篇文章稳定。

2. **`range-to-anchor.ts`** —— `selectionToAnchor(selection: Selection): Anchor | null`：解析当前选区，定位所在块级元素，计算块内 offset（块纯文本基准），跨块返回 null。返回 PRD 定义的五元组。

3. **`relocate.ts`** —— `relocate(anchor: Anchor, blocks: HTMLElement[]): RelocateResult`：实现三态重定位机：
   - hash 匹配 → 直接用 offset（快路径）。
   - hash 不匹配 → 在候选块内用 `selected_text` 子串查找；多次命中用前后 16 字 context 唯一化。
   - 全失败 → 降级为 `{ kind: 'page-level' }`（不丢失内容，作为页面级评论展示）。
   - 这是整个 PRD 风险最高的算法，测试必须穷尽三路径。

4. **`severity.ts`** —— 批注热度配色映射（未回复 cyan / 有回复 pink / 作者本人 green），复用 `shared/announcement-severity` 的 token 风格，输出可被 `AnnotationLayer` 和 `CommentCard` 共享的颜色决策。

## Acceptance criteria

- [ ] `block-id.ts` 实现 + 单测：同一块文本多次计算结果一致；空块/纯空白块的处理（约定返回固定哨兵或抛错，二选一并写注释）；跨 SSR 与客户端一致（不依赖 DOM runtime-only API）。
- [ ] `range-to-anchor.ts` 实现 + 单测：
  - 单块内选区 → 返回完整五元组，offset 正确。
  - 跨块选区 → 返回 null。
  - 选区起止在块边界（offset 0 / 末尾）的边界用例。
  - 注：jsdom 不完整支持 Selection/Range，测试用 polyfill 桩或抽象出可测的纯函数（输入 normalized range 数据，不直接依赖浏览器 API）。
- [ ] `relocate.ts` 实现 + **穷尽三路径单测**：
  - hash 匹配 → `{ kind: 'located', block, startOffset, endOffset }`。
  - hash 不匹配 + selected_text 单次命中 → located。
  - hash 不匹配 + selected_text 多次命中 → 用前后 16 字 context 唯一化命中或退化。
  - 全失败 → `{ kind: 'page-level' }`。
  - 选中文本部分修改（前缀/后缀/中间插入）的重定位行为。
- [ ] `severity.ts` 实现 + 单测：三态（未回复 / 有回复 / 作者本人）→ 对应 neon token；空状态降级。
- [ ] 所有算法为**纯函数**（除 block-id 取 DOM 文本外），可独立单测，不耦合 React。
- [ ] 测试模式：复制 `features/posts/ui/ArticleToc.test.tsx` 的 `buildTree` 段，Vitest table-driven。
- [ ] 不引入新依赖（SHA1 用 Web Crypto API `crypto.subtle.digest`，已内置；不装 crypto-js 等）。
