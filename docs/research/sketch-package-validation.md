# 手绘绘图库实验验收

日期：2026-10-09。需求入口：[PRD-0035](../prd/0035-可扩展手绘绘图库.md)。代码在当前项目的 `web/packages/sketch/`；实验消费方在 `web/src/features/lab/sketch-prototype/`，不再从 `/tmp` 原型工作区运行。正式 Mermaid 渲染仍使用 Rough.js。

## 结论

独立笔迹接口、共享几何、SVG/Canvas 和固定质量预算可以运行；完整彩漫不再因默认铅笔预算而缺图。当前整图并行显现**未达到普遍 60FPS**，尤其是铅笔。生成耗时低不能替代渲染与动画验收，不据此切换正式站点。

## 架构与消费

- 几何、生成编排、笔迹工厂、SVG/Canvas 后端分开；页面的 `Variant` 和播放时钟不进入包。
- 源码显式 `.ts` 导入；构建生成 ESM 与声明文件。导出符号的 TSDoc 记录单位、默认值、约束和失败边界。
- 外部 ribbon 笔迹只依赖根入口；真实浏览器在 SVG/Canvas 两端生成成功，没有修改核心和后端。
- 包构建、站点类型检查通过；提供方暂存树另行导出到隔离目录，单独构建包与检查不含实验页的站点类型通过。
- 从真实 tgz 在独立目录安装，TypeScript NodeNext 类型检查与 Node 原生执行通过；重复 seed 的输出一致。该消费者未使用 workspace 的源码入口。

## 浏览器与导出证据

使用真实 Chrome for Testing 151、macOS arm64、DPR 2。SVG 彩漫、Canvas 彩漫、草稿复线、压感尖角与自交、真实 Mermaid 和外部笔迹均查看了实际画面。

连续换色烟测复现过 `Cannot read properties of null (reading 'value')`：React 状态更新函数延后读取事件的 `currentTarget`。消费方改为在事件回调内先取颜色值；修复后连续切换 `#123456`、`#654321`，实际 palette 更新，生成时间标记和全部 path 的 d 保持不变，页面无错误。

额外通过页面键盘事件选择四倍速与并行编排，重播后暂停，progress 在等待期间保持 0.099604；恢复完整画面为 1。编排状态为 sequential=false。

- Canvas 实测 CSS 636×477，backing store 1272×954。
- 导出按钮下载 `sketch-comic-35.svg`，1164990 字节；通过 `file://` 独立打开并截图。SVG 含 927 个 path，没有 image、foreignObject 或 script，不依赖站点 CSS/JS；系统字体仍取决于运行环境。
- 时间轴实测：seek 到 0.4 → 播放 → 暂停后 progress 保持不变 → cancel 到 0 → 完整静态图回到 1。
- 七种填充分别走 SVG 序列化后 Image 解码与 Canvas 绘制。`evenodd` 孔洞中心像素两端均为纸张白色；同向子路径的 `solid + nonzero` 两端中心均为填充蓝色。其余样式同时记录了中心像素，但未据此声称全画面逐像素一致。
- 真实 Mermaid 的嵌套 tspan 曾同时提取外层行与内层词，形成数字重叠。改为只提取直接子 tspan；24 节点实测 24 条唯一标签，截图不再重复数字。

## 分阶段性能

原始结果、环境、配置和每次样本：

- [自然线条基准](./sketch-natural-benchmark.json)
- [铅笔基准](./sketch-pencil-benchmark.json)

实验页点击「运行阶段基准」可重放：真实 Mermaid 24/100 节点、32 段三次曲线、复合孔洞、完整彩漫、30000 节点压力场景。生成、SVG 构建/序列化、提交后 rAF、Canvas 冷/热 Path2D 与时间轴分别记录。热生成 7 次，提交等待 5 次，动画 60 次。记录为开发环境单轮结果，不是稳定跨设备性能保证；值为 0 表示低于计时分辨率。

以下为中位数，单位 ms；rAF 是回调间隔，不是 GPU 完成或实际呈现确认。时间轴测量为所有图元并行显现，交互页默认顺序编排，二者不能混称。

| 笔迹 / 场景 | 热生成 | SVG 动画 rAF | Canvas 动画 rAF |
| --- | ---: | ---: | ---: |
| 自然 / Mermaid 24 | 1.5 | 16.7 | 16.7 |
| 自然 / Mermaid 100 | 3.1 | 66.6 | 33.3 |
| 铅笔 / Mermaid 24 | 24.7 | 116.6 | 67.5 |
| 铅笔 / Mermaid 100 | 101.9 | 466.7 | 299.4 |
| 铅笔 / 完整彩漫 | 69.2 | 284.1 | 100.0 |

自然笔迹 Mermaid 24 的 SVG 构建中位数为 2.3ms，同骨架 Rough.js「生成 + SVG 构建」为 9.7ms；两者不是相同造型质量，不将其解释为全面性能优势。铅笔 complex 场景热生成 p95 达 410.4ms，原样保留，没有筛去异常样本。

30000 节点压力场景在两种笔迹下均抛命令超限，首次检测累计 600002 / 600000；没有输出半成品，也没有自动降低质量。预算只能约束合作插件申报的采样与命令，不能中断任意同步 JavaScript。
