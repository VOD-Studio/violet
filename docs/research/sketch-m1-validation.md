# 手绘绘图库 M1 验收记录

日期：2026-10-09。规格：[PRD-0035 M1 规格](../prd/0035-手绘绘图库M1规格.md)。对象：`web/packages/sketch` 0.2.0。

## 结论

- **自动验收通过**：行为测试、类型检查、构建、tarball 隔离消费与确定性复现。
- **性能部分达标**：路径、曲线与排线场景的生成加序列化快于 Rough.js；直线、矩形与关闭复画的圆角路径仍慢于 Rough.js，详见下表。
- **视觉验收未完成**：需要用户在 `/lab/sketch` 确认新库比 Rough.js 更好看，M1 才算完成。

## 行为测试

`pnpm exec vitest run packages/sketch` 共 7 项全部通过，覆盖规格中的 6 条验收：确定性与图元隔离、钉住端点、两种孔洞规则、闭合重叠与断笔越界、预算超限、外部扩展经 SVG 与 Canvas 渲染。

## 包消费

- `pnpm --filter @violet/sketch build` 产出 ESM 与声明文件；`path-data-parser` 作为外部依赖。
- `pnpm pack` 得到 `violet-sketch-0.2.0.tgz`，在仓库外的临时目录用 npm 安装：
  - TypeScript 5（NodeNext，`skipLibCheck: false`）类型检查通过；
  - Node 运行通过，同一 seed 两次生成的 SVG 相同。
- 打包体积用 esbuild 压缩，入口只引入生成与 SVG 后端：

| 库 | 压缩后 | gzip |
|---|---:|---:|
| @violet/sketch 0.2.0（draw + renderSvg） | 19,249 B | 8,612 B |
| Rough.js 4.6.6（generator + toPaths） | 27,426 B | 9,180 B |

## 性能

环境：Apple M2、macOS arm64、Node v23.10.0、Rough.js 4.6.6。每个场景预热 5 批、测量 21 批，下表为中位数（单位 ms）。只测生成与路径数据序列化，不含 DOM 与绘制。

- Rough.js 使用 PRD 基线配方（roughness 2.2、bowing 1.2、双笔复画）；本库使用自然手法、签字笔，线宽 1.25。
- 两者不是同一造型质量，结果不能解释为同质量下的绝对优劣。
- 原始数据：[sketch-m1-benchmark.json](./sketch-m1-benchmark.json)。

| 场景 | 图形数 | 生成 Rough / 本库 | 序列化 Rough / 本库 | 合计 Rough / 本库 | 每图形字符 Rough / 本库 |
|---|---:|---:|---:|---:|---:|
| 直线 | 1000 | 1.80 / 4.16 | 1.30 / 1.26 | 3.10 / 5.42 | 176 / 83 |
| 实心矩形 | 1000 | 4.81 / 15.59 | 8.35 / 11.78 | 13.16 / 27.37 | 867 / 951 |
| 实心圆角路径 | 1000 | 48.95 / 30.86 | 21.52 / 13.80 | 70.46 / 44.66 | 2152 / 1182 |
| 圆角路径描边 | 1000 | 29.78 / 28.51 | 15.23 / 12.34 | 45.01 / 40.85 | 1470 / 1065 |
| 圆角路径描边（Rough 关闭复画） | 1000 | 27.23 / 25.93 | 6.88 / 11.05 | 34.11 / 36.98 | 735 / 1065 |
| 128 段三次曲线 | 100 | 70.64 / 60.35 | 16.38 / 21.38 | 87.02 / 81.73 | 31855 / 23905 |
| 矩形排线 gap 4 | 100 | 4.32 / 7.26 | 6.15 / 2.87 | 10.46 / 10.12 | 10822 / 2375 |
| 矩形排线 gap 1 | 100 | 10.68 / 18.53 | 21.26 / 7.35 | 31.94 / 25.88 | 41040 / 6731 |

**未达标项**：直线与矩形这类极小图元的生成慢 2.3–3.2 倍，主要是每个图元的固定开销：展平、笔画规划、随机作用域与批次构造。Rough.js 对一条直线只生成两段贝塞尔。

**已采取的优化**：
- 定点数字格式化替代浮点 `toString`；
- 控制点位置与切线只求一次；
- 批次直接写入倍增的类型化数组；
- 两轮 PCG 随机；
- 细分跳过角点区间。

**下一步可验证的方向**：直线与无曲线多边形走专用展平快路径，不经二次曲线近似；批次与轮廓对象池化。

浏览器内单次测量（对照页显示，Chromium 无头，非基准）：Mermaid 24 节点场景，Rough.js 生成加 DOM 构建 14.7 ms、SVG 348.9 KB；本库 8.0 ms、84.8 KB。
