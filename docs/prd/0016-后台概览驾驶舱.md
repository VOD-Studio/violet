# PRD: 后台概览驾驶舱（admin overview）

## Problem Statement

`/admin` 概览页是占位页：硬编码假数据（"总用户数 47"、表情分组、已启用表情），与真实系统无关；快捷操作区只有 2 个入口，价值有限。与此同时后端 stats 能力已就绪但无人消费——`GET /admin/stats`（文章/评论/待审/浏览/用户五项总量 + 最近/热门文章）与 `GET /admin/stats/views`（日/月浏览趋势）已在 DDD stats 模块上线，前端零调用。

站长打开后台第一眼看到的页面，回答不了两个根本问题：**今天博客怎么样？有什么要我处理的？**

## Solution

重做 `/admin` 概览页为「站长驾驶舱」：12 列非对称 bento 网格，决策支持优先——待办行动卡置顶、每个数字带对比语境（环比/里程碑）、3 秒读懂核心状态。后端 stats 模块小步扩展（对比口径 + 趋势窗口参数化），前端新建 `admin-stats` feature 消费。

### 核心设计

**布局**（12 列 bento，层级靠 tile 尺寸）：

| Tile | span | 内容 |
|---|---|---|
| ① 今日浏览 Hero | 6 | 大数字 + 7 日 sparkline + 昨日环比 |
| ② 待审评论行动卡 | 2 | =0 绿勾「队列已清空」；>0 warning 高亮 + 直达审核页 |
| ③ 本周新评论 | 2 | 数字 + 上周环比箭头 |
| ④ 内容存量 | 2 | 文章/用户双小数字 |
| ⑤ 浏览趋势 | 8 | AreaChart，近 7 天/近 30 天/近 12 月三档 |
| ⑥ 热门文章 TOP5 | 4 | 浏览量横条排行，点击进文 |
| ⑦ 最近发布 | 7 | 时间线 + 状态徽章 |
| ⑧ 浏览里程碑 | 5 | 累计浏览 + 距下一整数刻度进度条 |

**创意机制**：
- ② 是行动卡不是数字卡——概览页唯一用色的强引导，把「待办」变成入口。
- ⑧ 把冷数字变情感锚点：「距下一个 10 万还差 3,204」。
- 空态人性化：无浏览记录 →「等待第一位读者」；无文章 → 引导去写作。

**技术选型**：图表复用 `@shared/ui/base/chart`（recharts，admin-system 已验证）；骨架屏 `shimmer-skeleton`；深浅主题自适应。

### 交付分期

| 期 | 内容 | 验收 |
|---|---|---|
| T1 | 后端：DashboardStats 补对比口径字段 + GetViewTrends 参数化 | 新字段返回正确，`?days=7` 生效，单测覆盖 |
| T2 | 前端：`admin-stats` feature（api 层 + tile 组件库 + bento 布局） | 组件单测、typecheck/biome 通过 |
| T3 | 页面接线：`admin.index.tsx` 重写为驾驶舱，删占位内容 | 浏览器实测真数据渲染，假数据清零 |

## User Stories

1. 作为站长，打开 `/admin` 3 秒内看到今日浏览与环比，判断流量走势。
2. 作为站长，有待审评论时第一屏看到高亮行动卡，一键直达审核页；无待审时看到「队列已清空」的安心状态。
3. 作为站长，通过浏览趋势图（7 天/30 天/12 月）识别内容长尾效果。
4. 作为站长，从热门文章排行直接进入高流量文章。
5. 作为站长，通过里程碑卡感知站点成长（距下一整数刻度的进度）。

## Implementation Decisions

### 后端（T1）

`DashboardStats` 新增字段（`post_views` / `comments` 现有数据聚合，零新表零迁移）：

```go
// TodayViews 今日浏览量（自然日，服务器时区）
TodayViews int64 `json:"today_views"`
// YesterdayViews 昨日浏览量，供前端算环比
YesterdayViews int64 `json:"yesterday_views"`
// WeekComments 本周（ISO 周）新评论数，含待审
WeekComments int64 `json:"week_comments"`
// LastWeekComments 上周评论数，供前端算环比
LastWeekComments int64 `json:"last_week_comments"`
```

`GetViewTrends` 参数化：`?days=7|30`（默认 30），daily 聚合窗口随之变化；monthly 固定 12 个月不动。参数校验白名单，非法值回退 30。

### 前端（T2/T3）

- 新 feature `web/src/features/admin-stats/`：`api/`（client/queries/keys，staleTime 1 分钟）+ `ui/`（8 个 tile + `OverviewBento` 布局）。
- bento 布局组件为 feature 私有；第二个页面复用时再提 `shared/ui`。
- DTO 为命名 interface（`model/types.ts`），对齐仓库前端约定。
- `admin.index.tsx` 删除全部占位假数据与快捷操作区（侧边栏已有全模块导航，页内入口冗余）。

### 权限

**零改动**。概览页属纯聚合只读页，跟随 `admin:access` 区域门禁，不建独立权限点（裁决依据：`.agents/skills/permission-points` 判断树第 1 条聚合只读页分支——已持区域门禁者看聚合数字不构成最小权限违规，无独立受众角色需求）。

## Out of Scope

- 其他后台页面的视觉统一（本 PRD 仅概览页）。
- 评论趋势曲线、各模块总量卡（订阅/公告/友链/媒体）——等真实需求。
- 细粒度权限点 `stats:view`。
- stats 接口缓存/物化（当前量级实时聚合够用）。
