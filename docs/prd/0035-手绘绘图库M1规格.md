## 公共契约

完整 TSDoc 见 `core/types.ts`。

```ts
interface Path {                       // 只含 M/L/C/Z；Q 升阶、A 转三次贝塞尔
  readonly verbs: Uint8Array;          // 0=M 1=L 2=C 3=Z
  readonly coords: Float64Array;
  readonly fillRule: "nonzero" | "evenodd";
  readonly bounds: Bounds;
}

interface Skeleton {                   // 展平结果：折线、累计弧长、角点
  readonly contours: readonly Contour[];
  readonly fillRule: Path["fillRule"];
}

interface Stroke {                     // 一次落笔到抬笔
  readonly points: Float32Array;       // [x, y, pressure, t] × n；pressure ∈ [0, 1]，t 为落笔时间（弧长单位）
  readonly curve: boolean;             // true：Catmull-Rom 控制点；false：折线顶点
  readonly closed: boolean;
  readonly pass: number;               // 0 主笔，> 0 草稿复线
}

interface Hand { readonly id: string; strokes(skeleton: Skeleton, ctx: DrawContext): readonly Stroke[] }
interface Pen  { readonly id: string; ink(strokes: readonly Stroke[], ctx: DrawContext, role: string): readonly InkBatch[] }
interface Fill {
  readonly id: string;
  generate(region: Skeleton, ctx: DrawContext, source: Path): { areas?: readonly Area[]; guides?: Skeleton };
}

interface Area { path: Path; role?: string; opacity?: number; clip?: boolean | Path }

interface Style {
  hand: Hand; pen: Pen; fill?: Fill;   // fill 缺省为实色
  fillHand?: Hand; fillPen?: Pen;      // 缺省沿用 hand / pen
  fillWeight?: number;                 // 填充线宽倍率，缺省 0.5
  lineRole?: (fillRole?: string) => string;  // 图元未指定 strokeRole 时由填充角色推导线色
}

interface DrawContext extends RandomSource {
  readonly width: number;              // 名义线宽，场景单位
  readonly precision: number;          // 展平容差
  readonly pixelScale: number;         // 场景单位到 CSS 像素
  readonly pinEnds: boolean;
  flatten(path: Path): Skeleton;
}

interface InkBatch {                   // 同一绘制属性合为一批
  readonly mode: "stroke" | "fill";
  readonly role: string;               // Palette 键
  readonly width?: number;
  readonly opacity?: number;
  readonly fillRule?: Path["fillRule"];
  readonly verbs: Uint8Array;
  readonly coords: Float32Array;
  readonly spans: Float32Array;        // 每个子路径的 [t0, t1] ∈ [0, 1]
  readonly ribbons?: Uint32Array;      // 条带子路径的 [n, c]：左侧 n 点、帽 c 点；其余为 [0, 0]
  readonly clip?: Path;
}

function draw(scene: Scene, options: DrawOptions): Drawing;
```

- **图元可覆盖线宽**：`SceneItem.lineWidth` 覆盖 `draw` 选项的名义线宽，用于卡通中外轮廓粗、细节细。
- **填充分两类产出**：`areas` 按数组顺序叠放，每块可带自己的颜色角色、不透明度与裁剪范围；`guides` 是图案骨架，交给填充手法变为笔画，再由填充笔成形，并以原路径裁剪。
- **随机**：通道是数字，扩展用 `channel("名称")` 在创建时哈希一次。描边与填充使用互不相关的随机作用域。
- **预算**：生成器统一计量输出顶点（`maxVertices`，默认 2000000）与笔画数（`maxStrokes`，默认 200000）。超限抛出 `BudgetExceeded`，不返回部分结果（ADR-0016）。
- **所有权**：`Pen.ink` 返回新建的批次，生成器就地归一化其 `spans`。
- **颜色**：只以角色出现在 `InkBatch.role`，换色不重新生成。

## 算法

### 几何

1. 解析沿用 `path-data-parser` 的 `absolutize` + `normalize`，得到 M/L/C/Z。
2. 展平：三次贝塞尔按 `√3/36·|p3−3p2+3p1−p0|` 误差估计分段近似为二次曲线，再按 Levien 解析式确定每段的折线点数。容差为 `precision`，默认 0.25，三次→二次与二次→折线各占一半。
3. 角点：命令接合处相邻切线夹角大于 28° 的顶点。阈值取低是因为凹角的转角往往不大（四角星的内凹顶点只有约 50°），光滑曲线在接合处的转角接近 0°，不会误判。展平结果按 Path 对象身份缓存，每条路径最多保留四种精度。

### 笔画规划

对每条子轮廓：

1. **闭合轮廓无角点**（圆、椭圆、圆角矩形）：一笔画完。起点相位随机，终点越过起点 `L × U(overlap)`。
2. **闭合轮廓有角点**：每个角按 `breakChance` 断笔，至少断一处；相邻段不断时连成一笔。断笔处两笔沿切线越界 `min(2w, w × U(0, 1) × overshoot)`，只有线宽量级；更长的越界会成为刻意的十字线头。终点越界取入射切线。
3. **开放路径**：在角点按同样规则断笔；路径两端不越界。
4. **超长笔画**：长于 `maxStroke / pixelScale` 时均分，接缝两侧各重叠 `0.5w`。
5. **草稿**：每笔复画 `passes` 次。复线共享同一低频形变，另加整体法向偏移与独立的高频、弯曲和端点随机。
6. **钉住**：`pinEnds` 的开放路径首尾位移在 `min(12w, 0.2L)` 内以 smoothstep 衰减为 0。

### 手法（每笔，全长 L 含越界）

1. **控制点**：基础点数 `ceil(L / spacing) + 1`，`spacing` 在 L ≤ 200 时取 80、L ≤ 400 时取 60，更长取 45。短线在感知上更接近直线（AlMeraj 2008）。相邻控制点切线夹角大于 30° 时二分细分，含角点的区间除外；每个笔画内部的角点前后各加 `±1.2w` 的近邻控制点以保持锐利。总数上限 256。
2. **位置与时间**：第 i 个基础点位于弧长 `L × m(τᵢ)`，`m(τ) = 10τ³ − 15τ⁴ + 6τ⁵`，`τᵢ` 等距。两端控制点更密，等 τ 步长对应钟形落笔速度，时间 `t = τ × L`。
3. **法向位移**：`d = A·noise(s/λ) + 0.3A·noise_hi(u/(λ/4)) + B·sin(π·m(τ)) + 端点误差`，其中：
   - `A = r × clamp(√(L/120), 0.35, 1.4)`：小图不毛糙，大图不呆板；
   - `λ = clamp(0.6L, 60, 260)`；
   - `B = b × U(−1, 1) × min(L, 300) × 0.008`。
   端点误差的法向与切向分量各为 `±0.4·r·w`，在两端 `min(0.3L, 40)` 内平滑衰减。只加在端点会因首尾控制点密集而形成钩子。
4. **连接**：向心 Catmull-Rom（Yuksel 2011）闭式转换为三次贝塞尔，避免扰动后出现尖点与自交。
5. **压力**：每个控制点写入压力 `pressure ∈ [0, 1]`：两端按 smoothstep 从 `tip` 升到 1，渐变长度 `min(taper × w, 0.45L)`，再乘 `1 + pressureNoise × noise`。压力只是数据，笔决定它影响粗细、浓淡还是透明度。

| 预设 | r 粗糙度 | b 弯曲 | breakChance | overshoot | passes | taper / tip |
|---|---:|---:|---:|---:|---:|---:|
| 工整 | 0.35 | 0.4 | 0.15 | 0.4 | 1 | 10 / 0.25 |
| 自然（默认） | 0.9 | 1.0 | 0.3 | 1 | 1 | 10 / 0.25 |
| 草稿 | 1.8 | 1.6 | 0.6 | 1.5 | 2 | 10 / 0.25 |
| 卡通勾线 | 0.5 | 0.6 | 0.1 | 0.5 | 1 | 14 / 0.05 |
| 工整 / 自然 / 草稿的填充手法 | 0.2 / 0.45 / 0.9 | 0.3 / 0.6 / 1 | 0 | 0 | 1 | 10 / 0.25 |

`pressureNoise` 默认 0.1，卡通勾线 0.12。

各预设的闭合重叠比例为 [0.04, 0.10]，`maxStroke` 为 360 CSS 像素。

### 笔

笔把笔画成形为渲染批次，并决定压力的用途。

**条带轮廓**（压感钢笔、轻压感签字笔、马克笔共用）：先把曲线笔画展平成样本（弦高误差 ≤ `precision`，直线段至少每 6 单位取一点，使压力渐变平滑），再沿笔画求笔尖的扫掠轮廓：

- 椭圆笔尖的半轴 `R = 全宽/2 × (min + (max − min) · p^γ)`，长轴角度 θ，短长轴比 a。笔尖在法向 n 上的支撑点是 `M·Mᵀn / |Mᵀn|`，`M = Rot(θ)·diag(R, aR)`；左侧取 `p + s(n)`，右侧取 `p − s(n)`。凸笔尖的扫掠包络恰是这条支撑点轨迹，扁笔尖由此得到随行笔方向变化的粗细，不需要额外的角度模型。
- 相邻切线夹角每超过 0.35 弧度，就在同一位置插入旋转中的法向，使左右两侧点数保持一致，外侧因此是圆弧连接；内侧的自交由 nonzero 填充吸收。
- 两端各加 6 点的笔尖圆帽，压力趋零时帽自然收尖。
- 条带多边形的点序固定为：左侧 n 点、末端帽 c 点、右侧 n 点（自末向首）、起端帽 c 点，并记入批次的 `ribbons`，供动画按前缀显现。

| 笔 | 笔尖 | 压力 → 宽度 | 其他 |
|---|---|---|---|
| 签字笔（默认） | 圆 | 恒宽，不生成轮廓，走原生描边 | 草稿复线另出一批，宽 0.75 倍、不透明度 0.7；`pressure > 0` 时改为条带，宽度在 `1 − pressure` 到 1 之间 |
| 压感钢笔 | 圆 | 0.08 到 1.25 倍，γ = 1.5 | 起收笔收尖 |
| 马克笔 | 扁，角度 −35°，短长轴比 0.28 | 0.85 到 1 倍 | 不透明度 0.78；每条笔画独立成批，不同笔画重叠处叠色加深，同一笔自身重叠不加深 |

### 填充

1. 扫描线支持孔洞与 `evenodd` / `nonzero`，输入为展平缓存。
2. 默认间距为填充线宽的 8 倍且不小于 5（填充线宽默认为名义线宽的一半，即名义线宽的 4 倍，同 Rough.js），角度 −41°。每行间距抖动 ±10%，每条排线角度抖动 ±1.5°。

| 图案 | 骨架（语义对齐 Rough.js 的 fillStyle） |
|---|---|
| `solid` | 原路径作为 `areas` 直接上色，不经笔 |
| `hachure` | 每个扫描区间一条线 |
| `cross-hatch` | 正交两组 hachure |
| `dashed` | 区间按 `1.7 × gap` 周期切段，奇偶行错开半周期 |
| `zigzag` | 相邻扫描行同序号区间连成一笔斜向往返折线；区间数变化时断开 |
| `zigzag-line` | 每个区间画成锯齿，行距 1.5 倍 |
| `dots` | 交错网格上的小闭合圆，半径 `max(填充线宽, 0.15 × gap)` |

3. 图案笔墨以原路径裁剪，孔洞内不出现笔墨。

### 卡通风格

`cartoonStyle` = 卡通勾线手法 + 压感钢笔（全宽 1.5 倍）+ 卡通填充，线色由 `lineRole` 取 `角色:line`。

卡通填充输出至多三块区域，依次叠放、依次淡入：

1. **底色**：原形状平移一个 `±misregistration`（默认 1.2）以内的确定性向量，与线稿轻微错位。
2. **阴影**（较短边 ≥ 14）：原形状与朝光源平移 `d = clamp(0.16 × 较短边, 3, 28)` 的副本以 evenodd 合并，裁剪到原形状，得到背光侧的月牙。
3. **高光**（较短边 ≥ 30）：原形状以包围盒中心缩到 0.8 并朝光源抬高 `0.05 × 较短边`，与朝背光平移 `clamp(0.07 × 较短边, 2, 10)` 的副本以 evenodd 合并，裁剪到内缩形状本身。

光源方向默认指向左上 `(−0.55, −0.83)`。月牙由图形几何得到，没有固定模板。

颜色由 `cartoonPalette` 在 OKLCH 中为每个基础色派生三个角色：

| 派生角色 | 明度 | 彩度 | 色相 |
|---|---|---|---|
| `角色:shade` | `0.8L − 0.015` | `1.08C + 0.01` | 朝 285° 转 20%，至多 28° |
| `角色:light` | `L + 0.5(1 − L) + 0.02`，不超过 0.985 | `0.75C` | 朝 90° 转 12%，至多 14° |
| `角色:line` | `0.4L` | `min(0.8C, 0.09)` | 不变 |

超出 sRGB 色域时降低彩度而保持明度与色相。派生色只依赖基础色，换色重新派生即可，几何不重新生成。

### 整图时间轴

笔画在生成时就带有落笔时间：每个控制点的 `t` 取弧长单位的累计值，两笔之间有固定停顿，填充晚于描边开始。生成器把它按图元总时长归一化后写入批次的 `spans`，同时在 `DrawnItem.duration` 记录图元的自然时长。动画不重新生成笔画。

**编排**（`createSchedule`）给每个图元分配时间窗口，图元自然时长为 `clamp(duration / speed, 0.12, 2.5)` 秒，`speed` 默认 600 弧长单位每秒：

| 模式 | 窗口 |
|---|---|
| `sequential` | 图元依次落笔，窗口首尾相接，总时长为各图元之和 |
| `parallel` | 全部同时开始并同时结束，总时长取最长的图元 |
| `stagger` | 按顺序错开起笔，彼此重叠，间隔缺省 `min(0.12, 6 / 图元数)` 秒 |

**播放器**（`createPlayer`）只维护时间：`play`、`pause`、`seek`（钳制到 [0, 总时长]，不改变播放状态）、`restart`、`cancel`、可变的 `rate`。每次取消、重启或跳转递增一个代数，使旧的帧回调与完成回调失效；时钟与 rAF 可注入。

**显现**由渲染器按轨迹（每个子路径一条，`batchTracks`）完成：

| 轨迹 | 内容 | SVG | Canvas |
|---|---|---|---|
| stroke | 恒宽描边 | 每子路径一个元素，`pathLength=1` 加 `stroke-dashoffset` | `setLineDash`，长度取控制多边形近似值，完成时改为整条绘制 |
| ribbon | 变宽条带 | 进行中只设 `d` 为前缀多边形（左侧前 k 点加右侧前 k 点，不含圆帽），完成时恢复整条 | 同样构造前缀 Path2D |
| area | 区域填充（含 evenodd 合成的月牙） | 整体一个元素，不透明度按 smoothstep 淡入 | 同 |

区域批次的多个子路径共同构成一个形状，必须整体显现，不能拆开。不使用 mask 与 scale、滑入。SVG 的 `seekSvg` 只处理状态变化与进行中的图元，每帧成本与同时进行的笔画数成正比；`mountSvg` 带 `schedule` 时画面保持完整，不立即进入动画。

### 随机

`random(ch, i) = pcg((pcg(root ^ ch) + i × 0x9e3779b1) | 0) / 2³²`，`root = pcg(seed ^ pcg(hash(图元 id)))`。`noise` 是以同一哈希生成格点梯度的一维梯度噪声。同一输入、选项、版本与 seed 输出逐位相同；修改一个图元不改变其他图元。

## 渲染

- **SVG**：`renderSvg` 不依赖 DOM。每个图元一个 `<g>`，每个批次一个 `<path>`；坐标用定点格式化，默认保留 2 位小数。只有带裁剪的批次建立 `clipPath`，不使用 mask。`mountSvg` 构造元素，`updateSvgPalette` 只改颜色属性。
- **Canvas**：直接调用 `Path2D` 的 `moveTo` / `lineTo` / `bezierCurveTo` 构造路径，不经字符串。Path2D 按批次缓存，并按 CSS 尺寸与 DPR 调整像素尺寸。

## 验收

### 视觉（出口条件）

实验页 `/lab/sketch` 并排展示 Rough.js（线上 Mermaid 配方）与本库：卡通插画、基础图元、7 种填充、复合孔洞与真实 Mermaid 24 节点图。可切换五种笔（签字笔、轻压感签字笔、压感钢笔、马克笔、卡通）、三档手法、seed、1×/3× 缩放和 SVG/Canvas 后端；时间轴控制条提供播放、暂停、重播、进度拖动、顺序/并行/交错与 0.5× 到 4× 变速，只作用于本库一侧。**由用户确认新库更好看后，M1 才算完成。**

### 行为测试（永久，经公开接口）

1. 相同输入与 seed 输出逐位相同；修改一个图元或其填充，不改变其他图元及该图元的描边几何。
2. `pinEnds` 路径首尾与原坐标的距离在 Float32 精度内（小数点后 3 位）。
3. `evenodd` 与 `nonzero` 孔洞内部不出现任何填充笔墨的顶点或控制点，且裁剪路径保留原填充规则。
4. 闭合无角点轮廓的笔画首尾重叠；有角点轮廓在断笔处越界。
5. 预算不足抛出 `BudgetExceeded`，不返回结果。
6. 外部 Hand / Pen / Fill 只从包根入口导入即可生成，并能用 SVG 与 Canvas 两个后端渲染。
7. 压感钢笔两端收尖、中段最宽；扁笔尖的厚度取决于行笔方向；条带两端有帽且轮廓闭合；签字笔默认走原生描边。
8. 马克笔每条笔画独立成批，同一笔自身不叠色。
9. 卡通填充按底色、阴影、高光三层输出，线色取派生线色，阴影随图形大小变化，过小的图形只上底色；派生色相对基础色偏冷或偏暖而非叠黑。
10. 编排的三种模式窗口关系；播放器的播放、暂停、恢复、跳转、变速、取消与重播，旧完成回调不影响新一次播放。
11. SVG 与 Canvas 的按时间显现：起点全部隐藏、中途部分显现、终点与静态画面一致；合成区域不被拆成子路径。
