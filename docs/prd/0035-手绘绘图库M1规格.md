## 公共契约

签名可在实现中微调命名，但数据形态与职责边界以此为准。

```ts
/** 只含 M/L/C/Z 的绝对坐标路径；Q 升阶、A 转三次贝塞尔后得到。 */
interface Path {
  readonly verbs: Uint8Array;        // 0=M 1=L 2=C 3=Z
  readonly coords: Float64Array;     // 按 verb 依次存放坐标
  readonly fillRule: "nonzero" | "evenodd";
  readonly bounds: Bounds;
}

/** 一次落笔到抬笔。 */
interface Stroke {
  readonly points: Float32Array;     // [x, y, pressure, t] × n，t 为图元内归一化时间
  readonly curve: boolean;           // true 时 points 为 Catmull-Rom 控制点，渲染前转三次贝塞尔
  readonly closed: boolean;
}

interface Hand {
  readonly id: string;
  /** 把展平后的骨架变成笔画；不得修改输入，随机只能来自 ctx。 */
  strokes(skeleton: Skeleton, ctx: DrawContext): readonly Stroke[];
}

interface Pen {
  readonly id: string;
  ink(strokes: readonly Stroke[], ctx: DrawContext, role: string): readonly InkBatch[];
}

interface Fill {
  readonly id: string;
  /** 返回区域墨块，或交给笔成形的图案笔画。 */
  generate(region: Skeleton, ctx: DrawContext): { areas?: readonly Path[]; strokes?: readonly Stroke[] };
}

interface Style {
  hand: Hand;
  pen: Pen;
  fill?: Fill;
  fillHand?: Hand;                   // 缺省为 hand 的低粗糙度变体
  fillPen?: Pen;                     // 缺省为 pen 的 0.5 倍线宽
}

interface DrawContext {
  readonly width: number;            // 名义线宽，场景单位
  readonly precision: number;        // 展平容差，场景单位
  readonly pixelScale: number;       // 场景单位到 CSS 像素的比例，质感可见性的判据
  readonly pins: PinSet;             // 必须精确的端点
  random(channel: number, index: number): number;      // [0, 1)
  noise(channel: number, x: number): number;           // [-1, 1] 一维梯度噪声
  readonly budget: Budget;
}

/** 渲染单元：同一绘制属性的笔墨合为一批。 */
interface InkBatch {
  readonly mode: "stroke" | "fill";
  readonly role: string;             // Palette 键
  readonly width?: number;
  readonly opacity?: number;
  readonly verbs: Uint8Array;
  readonly coords: Float32Array;
  readonly spans: Float32Array;      // 每个子路径的 [t0, t1]，M3 动画使用
  readonly clip?: Path;
}

interface SceneItem {
  id: string;
  path: Path;
  style?: Style;                     // 缺省用 draw 选项中的 style
  strokeRole?: string;               // 缺省 ink；none 不描边
  fillRole?: string;                 // 缺省不填充
  pinEnds?: boolean;                 // 开放路径首尾保持精确，用于连线与箭头锚点
  transform?: Matrix;
}

function draw(scene: Scene, options: DrawOptions): Drawing;
```

- 随机通道是数字。外部扩展用 `channel("名称")` 在创建时哈希一次，热循环中不拼接字符串。
- 预算由 IR 构建器统一计量输出顶点与笔画数，扩展不再自行申报命令数；超限抛出 `BudgetExceeded`，不返回部分结果（ADR-0016）。
- 颜色只以角色出现在 `InkBatch.role`，换色不重新生成。

## 算法

### 几何

1. 解析沿用 `path-data-parser` 的 `absolutize` + `normalize`，得到 M/L/C/Z；圆弧转三次贝塞尔。
2. 展平：三次贝塞尔先按误差估计分段近似为二次曲线，再按 Levien 解析式预估每段的折线点数，坐标写入预分配的 `Float64Array`，同时累计弧长。容差为 `precision`，默认 0.25。
3. 角点：相邻切线夹角大于 `cornerAngle`（默认 55°）的顶点标记为角点。展平结果按 Path 对象身份缓存，缓存有上限。

### 笔画规划

对每条子轮廓：

1. 按角点切成若干段。
2. **闭合轮廓无角点**（圆、椭圆、圆角矩形）：一笔画完。起点相位随机，终点越过起点 `overlap = L × U(0.04, 0.10)`。
3. **有角点**：每个角以概率 `pBreak` 断笔，相邻段不断时连成一笔，例如矩形拆成两个 L 或四笔。断开处两笔沿切线越界 `overshoot = clamp(w × U(0.5, 1.5) + 0.03 × 段长, 0, 6w)`。
4. **超长笔画**：长于 `maxStroke`（默认 360 场景单位，按 `pixelScale` 换算）时拆开，接缝错位不超过 `0.5w`。
5. **草稿**：每笔复画 `passes` 次。复线共享同一低频形变，只替换高频噪声与端点随机。
6. **钉住**：`pinEnds` 的开放路径首尾不越界、不位移，偏移量在两端各 `min(12w, 0.2L)` 内以平滑步进衰减为 0。

### 手法（每笔）

1. **控制点**：数量 `N = clamp(ceil(L / spacing), 3, 64)`，`spacing` 按长度分档：L ≤ 200 取 60，L ≤ 400 取 45，更长取 35。参照 AlMeraj 的 Δτ 分档，长线更多变化。
2. **位置**：第 i 个控制点的弧长位置 `s_i = L × m(i / (N−1))`，其中 `m(τ) = 10τ³ − 15τ⁴ + 6τ⁵`。两端更密，等时间步对应钟形落笔速度，`t_i = i / (N−1)`。
3. **法向位移**：`d_i = A × noise(ch, s_i / λ) + B × sin(π s_i / L) + 端点抖动`，其中：
   - `A = r × g(L)`，`g(L) = clamp(√(L / 120), 0.35, 1.4)`：小图不毛糙，大图不呆板；
   - `λ = clamp(0.45L, 40, 240)`；
   - `B = b × U(−1, 1) × min(L, 300) × 0.008`。
4. **连接**：控制点用向心 Catmull-Rom（Yuksel 2011）连接，闭式转换为三次贝塞尔，避免扰动后出现尖点与自交。
5. **压力**：M1 恒为 1，仍写入通道。

| 预设 | r 粗糙度 | b 弯曲 | pBreak | passes |
|---|---:|---:|---:|---:|
| 工整 | 0.35 | 0.4 | 0.3 | 1 |
| 自然（默认） | 0.9 | 1.0 | 0.6 | 1 |
| 草稿 | 1.8 | 1.6 | 0.85 | 2 |

### 签字笔（M1 恒压路径）

圆笔尖、恒压时不生成轮廓：所有笔画输出为一个 `mode: "stroke"` 批次，宽度为 `width`，用原生圆端帽与圆连接。草稿复线另出一批，线宽 0.75 倍、透明度 0.7。

### 填充

1. 区域判定沿用原型扫描线算法，支持孔洞与 `evenodd` / `nonzero`，输入改为展平缓存。
2. 默认间距 `gap = max(4w, 5)`，角度 −41°（与 Rough.js 默认一致，便于对照）。每条排线的间距与角度带小幅确定性抖动：间距 ±10%，角度 ±1.5°。
3. 各图案产出的笔画都经 `fillHand` 与 `fillPen` 成形：

| 图案 | 产出 |
|---|---|
| `hachure` | 每个扫描区间一笔 |
| `cross-hatch` | 正交两组 hachure |
| `dashed` | 区间按 `1.7 × gap` 周期切段 |
| `zigzag` | 每个区间一条折线笔画 |
| `zigzag-line` | 相邻扫描线连成一笔往返折线 |
| `dots` | 每点一个小闭合笔画 |
| `solid` | 区域墨块（`areas`），不经笔 |

4. 排线越界部分由原区域 `clip` 裁掉。孔洞内不得出现笔墨。

### 随机

`random(ch, i) = pcgHash(seed, itemHash, ch, i) / 2³²`。`itemHash` 由图元 id 哈希一次。`noise` 为由同一哈希生成格点梯度的一维梯度噪声。同一输入、选项、版本与 seed 输出逐位相同；修改一个图元不改变其他图元。

## 渲染

- **SVG**：每个图元一个 `<g>`，每个 `InkBatch` 一个 `<path>`，`d` 在构建时从 typed array 生成，默认保留 2 位小数，可配置。有 `clip` 才建 `clipPath`；不建立 mask。`updateSvgPalette` 只改颜色属性。
- **Canvas**：直接调用 `Path2D` 的 `moveTo` / `lineTo` / `bezierCurveTo` 构造路径，不经字符串；Path2D 按批次缓存。按 CSS 尺寸与 DPR 调整画布像素尺寸，并据此给出 `pixelScale` 建议值。

## 验收

### 视觉（出口条件）

实验页 `/lab/sketch-prototype` 改为 Rough.js 与新库并排对照：

- 基础图元表（直线、矩形、圆角矩形、圆、椭圆、折线、多边形、曲线、复合孔洞路径）；
- 7 种填充表；
- 真实 Mermaid 24 节点图。

三种手法均可切换，并以 1× 与 3× 缩放查看。由用户确认新库更好看后，M1 才算完成。

### 行为测试（永久，经公开接口）

1. 相同输入与 seed 输出逐位相同；修改一个图元或其填充，不改变其他图元及该图元的描边。
2. `pinEnds` 路径首尾与原坐标的距离小于 1e-6。
3. `evenodd` 与 `nonzero` 孔洞中心采样点不被任何填充笔墨覆盖（几何判定）。
4. 闭合无角点轮廓的笔画首尾存在重叠；有角点轮廓在断笔处越界。
5. 预算不足抛出 `BudgetExceeded`，不返回结果。
6. 外部 Hand / Pen / Fill 对象只从包根入口导入即可生成，并能用 SVG 与 Canvas 两个后端渲染。

### 性能

用 PRD 基线的同一脚本与环境，对照 8 个 Rough.js 场景，采用自然手法、签字笔、默认填充：

- 生成加 SVG 序列化的中位数与 p95 不高于 Rough.js；
- 输出字节数不高于 Rough.js。

结果写入 `docs/research/`。未达标时如实记录原因，不调低手法或填充密度。

### 包

`typecheck`、`build`、`pack` 后在隔离目录从 tarball 安装并完成类型检查与运行。记录只引入 SVG 后端时的打包体积，并与 Rough.js 对比。
