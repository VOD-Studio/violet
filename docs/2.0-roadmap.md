## M1 · TanStack Router 迁移

### 为什么迁移
- **类型安全**：`<Link to="/blog/$slug">` 自动校验路径参数，`useParams()` 返回的类型化对象，路由变更时编译期报错。
- **代码生成路由树**：`routeTree.gen.ts` 由 `@tanstack/router-plugin` 自动生成，避免手写 `<Routes>` 集中表的维护成本。
- **loader / beforeLoad**：内置数据预取与守卫，与 react-query 的 `preload` / `ensureQueryData` 天然契合。
- **生态统一**：Query + Router + (未来) Form 同源，DevTools 一体。

### 迁移范围（22 文件）
路由树定义：`src/App.tsx`（约 350 行 `<Routes>/<Route>`）
守卫：`src/middleware/auth.ts`（`redirect()`）、`src/App.tsx`（`<Navigate>`）
Hooks 使用方（import 源切换）：
```
src/middleware/auth.ts
src/App.tsx
src/lib/navigation.ts
src/components/layout/{Header,AdminLayout,AdminSidebar,AnimatedOutlet}.tsx
src/features/auth/components/{LoginForm,RegisterForm,VerifyEmailForm}.tsx
src/features/posts/components/PostCard.tsx
src/pages/Home/{HeroSection,RecentPostsSection}.tsx
src/pages/Projects/{ProjectsGrid,slug}.tsx
src/pages/admin/Post/{index,Edit/index}.tsx
src/pages/admin/Dashboard/{index,PopularPostsTable}.tsx
src/pages/blog/slug/{index,ArticleHeader,ArticleError}.tsx
src/pages/profile/index.tsx
```

### API 对照表

| react-router v7 | @tanstack/react-router | 备注 |
|---|---|---|
| `<Link to="/x">` | `<Link to="/x">` | to 受类型校验 |
| `useNavigate()` → `navigate("/x")` | `useNavigate()` → `navigate({ to: "/x" })` | 改为对象式 |
| `useParams()` | `Route.useParams()` 或 `useParams({ strict })` | 推荐挂在 route 上 |
| `useLocation()` | `useLocation()` / `useRouterState()` |  |
| `useSearchParams()` | `useSearch({ strict })` | 搜索参数类型化 |
| `<Outlet>` | `<Outlet />`（`<RouteComponent />`） |  |
| `loader()` + `redirect()` | `beforeLoad` + `throw redirect()` | 守卫在路由定义内 |
| `<Navigate to>` 组件 | `redirect()` 在 `beforeLoad` | 不再用渲染式跳转 |
| `<Routes>/<Route>` 集中表 | `createRoute` + 代码生成 `routeTree.gen.ts` |  |

### 分阶段执行

- **M1.1 依赖与脚手架**
  - 安装 `@tanstack/react-router` `@tanstack/router-devtools` `@tanstack/router-plugin`
  - `vite.config.ts` 接入 `TanStackRouterVite()` 插件
  - 生成 `src/routeTree.gen.ts`（`.gitignore` 排除）
  - 验证：dev 可起，路由树为空时不报错

- **M1.2 路由树迁移**
  - `createRootRoute` + `createRoute` 重写 `src/App.tsx` 的约 20 条路由
  - 保留 `React.lazy` 懒加载（TanStack 支持 `lazy` 选项）
  - 保留 ErrorBoundary（TanStack `errorComponent`）

- **M1.3 守卫迁移**
  - `middleware/auth.ts` 的 `redirect()` → 路由 `beforeLoad` 中 `throw redirect({ to: "/login" })`
  - `src/App.tsx` 的 `<Navigate>` 渲染式跳转 → `beforeLoad` 声明式
  - `src/lib/navigation.ts`（命令式导航封装）改用 `router.navigate({ to })`

- **M1.4 Hooks 全量切换**
  - 上述 20 个 hooks 使用方改 import 源
  - `useNavigate` 调用点改为对象式 `navigate({ to })`
  - `useParams` 优先改用 `Route.useParams()` 获得类型

- **M1.5 清理与验证**
  - 移除 `react-router` 依赖
  - `pnpm typecheck` + `pnpm lint` + `pnpm build` 全绿
  - `pnpm test`（更新 `src/middleware/auth.test.ts` 适配新守卫签名）

## M2 · ReactBits 组件库接入

### 接入模式
ReactBits 免费版**无 npm 包**，采用 copy-paste：
- 组件代码落库到 `src/components/reactbits/<category>/<Component>/`
- 通过 [ReactBits MCP](https://reactbits.dev/get-started/mcp)（复用 shadcn MCP，装在客户端）检索/拉取组件
- 每个组件按其文档单独安装运行时依赖

### 依赖策略
- ✅ **已具备**：`motion`（framer-motion v12）、`tailwindcss` v4、`clsx`、`tailwind-merge`
- 按组件按需补装，例如：
  - 3D 类组件 → `three`
  - 像素/模糊图 → `blurhash`
  - 图表类 → 复用现有 `recharts`
- 每次新增依赖须在 PR 描述注明用途与体积影响

### 目录约定
```
src/components/reactbits/
├── animations/      # 文字/进场动效
├── backgrounds/     # Ribbons、Particles 等背景
├── components/      # ScrollStack、Counter 等交互组件
└── text/            # 文字特效
```
> 复用项目既有 `cn()` (`@/lib/utils`)、Tailwind v4 token 与 `src/index.css`，不改主题体系。

### 首批落地清单（待 M1 完成后细化）

- 项目页：ScrollStack 卡片堆叠展示
