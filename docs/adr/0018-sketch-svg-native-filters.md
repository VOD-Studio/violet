# 手绘质感允许使用 SVG 原生滤镜

本决策修订 [ADR-0017](0017-sketch-vector-ink.md) 的纯矢量约束：手绘绘图库的质感可以使用 SVG 原生滤镜表达（如 `feTurbulence`、`feDisplacementMap`），仍不嵌入位图纹理。首版原型用路径表达铅笔纤维与颗粒，输出约 36 万条命令，且细节处于亚像素尺度几乎不可见；原生滤镜能以极少的数据表达同等或更好的颗粒质感。

导出的 SVG 仍可独立打开，不依赖站点 CSS、脚本或外部图片；滤镜结果由浏览器光栅化，不承诺跨浏览器像素一致。Canvas 后端须以等价的矢量或滤镜手段呈现同一质感，具体方式由正式规格确定。路径与滤镜的选择属于各支笔的实现，输出成本仍遵循 [固定质量与显式超限策略](0016-sketch-fixed-quality.md)。
