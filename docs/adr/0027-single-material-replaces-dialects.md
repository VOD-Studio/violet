# 单一材质取代三种视觉方言

设计稿「基础」要求全站一套材质：纸面、纸片、凹陷三层表面，一种软影（`0 4px 24px rgb(0 0 0 / .05)`，深色下纸片加 1px 描边），主要动作为墨色，季节色只做装饰、进度与选中点。因此 public、tool、immersive 三种方言全部取消。本 ADR 取代 ADR-0015 中视觉方言边界的表述，以及 ADR-0024 中“保留三种方言、工具方言的主要动作为高对比中性色”一句；ADR-0015 的主题切换器水合规则与样式文件分层、ADR-0024 的种子色算法与对比度门槛继续有效。

主要动作色全站取高对比中性色：公开页与登录入口的主要按钮不再使用品牌色，这是用户可见的改变。沉浸方言随之取消：灯箱遮罩改用设计稿的 90% 纸色加 20px 背景模糊，后台媒体查看器同样改用纸色遮罩，不再有近黑舞台。方言相关的 CSS、`dialect-*` 类与对应测试一并删除，不留兼容层。

材质的明度层级与旧方言相反：纸片比纸面浅，而原先卡片比背景深。依赖旧明度关系的组件要逐页在浏览器里验收。
