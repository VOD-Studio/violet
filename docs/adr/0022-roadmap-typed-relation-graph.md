# 路线图条目关系是带类型的有向图，阶段不由关系推导

路线图条目之间的关系带类型（扩展、修复、阻塞，由系统固定）、有方向，同一类型内不成环，不是单父树：一个条目可以有多个前置或后继，例如一次修复同时阻塞多个后续功能。环检测按类型分别进行：「A 扩展 B」读作 A 在 B 之后，「A 阻塞 B」读作 A 在 B 之前，方向语义相反，跨类型合并检测会误判。阶段始终由管理员手动设置，关系只产生派生展示：衍生条目的阶段分布与「被阻塞」标记。

否决了单父树，它无法表达多前置与阻塞；也否决了由衍生条目自动推导父条目阶段，它与手动拖拽冲突，「已完成后又发现 bug」会把已完成的大条目拉回开发中。

代价是需要环检测，连线容易交叉，因此画布上用线型区分类型、选中条目时高亮相关连线并淡化其余，另提供隐藏连线开关，窄屏改用卡片标记。第一版关系仅限同一项目内；新增类型（如「相关」）或跨项目关系需要扩展类型枚举与迁移，列入后续规划。
