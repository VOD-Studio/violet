# 前台页面复用现有组件，旧页面稿不覆盖组件契约

2026-11-12，产品负责人确认前台页面稿早于部分组件设计。页面改版先复用 `@violet/ui` 和站点已有组件，以现有组件的外观、交互及 API 为准；页面稿负责布局、内容层级与页面级流程。不能为了复刻旧稿手写同类控件、复制组件 CSS，或把现有组件退回旧交互。仅在现有能力确有缺口时提出最小扩展，通用能力与业务接入分开提交。

这项决定取代 ADR-0026 中“设计稿优先”对已有组件的适用部分；其余已采纳的产品裁决继续有效，包括登录后聊天的一级入口、多表情回应及文章阅读行为。没有新画板的页面不因本轮改版被删除功能。

组件 UED 画板与组件展示画板从工作树移除，保留基础、图标、前台、后台和状态稿；旧组件设计可从 Git 历史追溯。组件契约留在包内文档、实现与测试中，保留的页面原稿仍含旧组件的 `dc-import`，不再承诺离线完整渲染。

`/ui` 组件陈列室及其专属实现、入口与测试下线，不按旧站点结构稿迁入项目文档。`@violet/ui` 继续维护；行为测试、真实 tarball 消费和实际业务页面的浏览器验收不以陈列室存在为前提。
