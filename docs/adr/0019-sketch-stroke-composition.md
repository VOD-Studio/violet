# 手绘绘图以笔画为中间表示并分维度组合

手绘绘图库把结果拆成三个独立维度：笔（笔尖、压力作用与墨/质感）、手法（扰动、断笔、越界与复线）、填充（区域上色方式）；风格是三者与明暗的组合预设。压感是每支笔的属性，不是一种笔。描边、填充排线、箭头与装饰统一先生成笔画——一次落笔到抬笔，逐点携带位置、压力与时间——再经同一支笔成形。

首版原型以「整支笔包办一切」为扩展单元，导致同一算法的参数被当成不同笔、压感无法用于其他笔、彩漫明暗被塞进笔里，填充排线也与描边风格割裂。按维度组合后，扩展方只需替换一个维度；风格一致与按落笔时间的动画由笔画表示天然提供。代价是核心须定义并长期维护笔画中间表示与各维度接口，变更它们会影响全部扩展。
