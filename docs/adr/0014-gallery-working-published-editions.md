# 图集使用工作稿与公开版本双快照

图集编辑包含选图、排序和逐项说明，已发布作品继续修改时不能把半成品直接暴露给访客。图集因此保留工作稿与公开版本两个有效快照：保存只更新工作稿，发布才原子替换公开版本；首次修改已发布内容时按需复制工作稿，旧的无效快照随发布或删除清理，不提供无限修订历史。

## Considered Options

- 直接更新已发布记录：表少、写入简单，但任一次自动保存都会改变线上作品，作者无法先完成整组调整再发布。
- 编辑前先撤回：避免线上出现半成品，但每次维护都会让公开地址暂时失效。
- 保留完整修订历史：以后可以回滚和固定版本分享，但会长期占用素材引用，并扩大清理、查询和权限范围。

## Consequences

- 公开读取始终只读公开版本，后台编辑始终只读写工作稿。
- 保存、发布、快照清理和素材引用变化必须在同一数据库事务内完成。
- 图集没有通用版本历史；需要回滚能力时另行设计，不能默认保留所有工作稿。
