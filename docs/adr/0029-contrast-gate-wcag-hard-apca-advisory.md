# 对比度门槛：WCAG AA 为硬约束，APCA 分级告警

ADR-0024 要求文字与控件组合同时通过 WCAG 2.2 AA 与 APCA，运行时求解的目标值也由 APCA 折算而来，并用 1° 步长遍历 12290 个主题。数据显示这对四季预设过严：设计稿的 fg、muted、accent 四季明暗都过 WCAG AA，只有危险色、成功色与春季深色强调字不过 APCA 的 Lc 75，而求解器为此把深色状态文字挤成淡粉（L 0.874、C 0.067，设计稿是 L 0.74、C 0.14）。本 ADR 取代 ADR-0024 中“同时通过 WCAG 与 APCA”的表述。

WCAG 2.2 AA 是硬约束：正文与次要文字 4.5，大字与控件边界 3.0，运行时求解与测试都只按它判定，目标值在 AA 上留固定余量。APCA 按用途分级只告警：正文 Lc 90，次要文字 75，状态文字 45，装饰与边框不约束；测试里报告低于分级值的组合，但不让测试失败，也不再参与求解。“提高对比度”档保留，WCAG 取 7，运行时仍求解。

自定义主题与人设身份色取任意种子，继续按 AA 做 1° 步长遍历。四季预设的取值来自设计稿，改为直接对 16 套色阶（四季、明暗、标准与提高对比度）断言，不再依赖遍历。设计稿里浅色成功色在着色底上只有 4.3，低于 AA，落地时要把成功色调暗或降低着色比例，而不是放宽 AA。
