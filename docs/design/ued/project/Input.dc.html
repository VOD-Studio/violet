变体

同一个输入框的四种变体，一行一个状态，四列并排。高度、内边距、槽和键盘行为完全一样，只有静止、悬停时的画法不同；聚焦、出错、通过时都用同一个焦点色。点击任意一格可以真的聚焦。

结构

外壳管高度、圆角、底色、聚焦和出错；两边的槽放图标、文字、清除钮、键帽；中间是输入区。

动效

边框、光晕和涟漪是同一个焦点色（季节色混 40% 墨色）；出错是危险色，通过是成功色。涟漪最远只扩到 5px。输入框本身不位移不缩放，文字不跳。

键盘与无障碍

可访问名称输入框自己不带可见标签；单独使用时写 aria-label
出错aria-invalid 切换出错外观；错误文案放在输入框外面
清除钮aria-label「清除」，Tab 可达；输入区按 Esc 同样清空，已空则不拦截
显隐密码aria-pressed 表示状态；type 在 password 与 text 间切换，光标位置保持
只读与禁用只读可聚焦可复制；禁用不进 Tab 顺序
触屏inputmode 和 autocomplete 写全（email、username、one-time-code），字号 16
