键盘

⌘K / Ctrl K任意页面打开；已经打开时关闭
↑ ↓在所有结果之间移动，跨过分组，到头循环；只有指针真的移动时才改当前项，滚动列表不会改
↵当前项亮一下（季节色底 140ms）后执行并收起；⌘↵ 在新标签页打开（文章与页面）
Esc有输入时先清空；在子页面时回到上一级；都没有时关闭
退格输入框为空且在子页面时回到上一级
读屏输入框 role="combobox"，aria-activedescendant 指向当前项；列表 role="listbox"，分组 role="group"

结果

不输入最近打开的 3 篇文章、常用页面、常用命令
匹配标题、路径、命令名里包含输入的字就算，不区分大小写；匹配到的字加浅季节色底
排序组的顺序固定为文章、页面、命令；组内标题开头就匹配的排前面
全文输入两个字以上时，去正文里搜，等待时在最后一组显示两行骨架；结果回来后插在最后
没有结果一句「没有找到」，下面给「在全文里搜索」作为唯一一项，回车即可
子页面「切换主题」这类需要再选一次的命令进入子页面，输入框左边显示层级

动效

命令面板是用键盘叫出来的，没有按钮可以长出来，所以按它自己的用法设计：先是一个输入框，然后才是结果。输入框从上方 8px 处落下并由虚变实，列表随后往下展开，前 8 项依次浮现；之后列表的高度跟着结果数量变化。进入「切换主题」这类下一级时，列表往左推进，退回时往右。执行时当前项亮一下再收起。遮罩、曲线与对话框共用，面板不缩放。
