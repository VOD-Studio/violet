规格

外观表格不套卡片，直接放在页面纸片上；表头一条细线，行与行之间一条细线；数字右对齐、等宽
尺寸表头 36，紧凑 32；行高 48，紧凑 40；单元格左右 12；展开列 32，勾选列 36；行内图标按钮 28
排序箭头只在悬停或正在排序时出现：悬停是浅色双向箭头，排序后换成实心的上或下箭头，列名加深；点一下升序，再点降序
选择勾选跨页保持；全选只管本页，部分选中时显示横线；整页都选上后，可以一键选中全部结果
批量操作有选中项时，在表头原位淡入一条操作栏（160ms），盖住列名但不改变高度，取消选择后淡出；不再浮在页面底部
展开箭头转 90°，下面展开一块缩进的浅底面板，左边与标题对齐，放摘要与几项字段，不重复标题；高度展开 280ms
行内操作编辑与更多两个按钮只在悬停或聚焦该行时出现
列左上角按钮控制显示哪些列，列宽可以拖动（最小 80），都记在这台设备上，可以一键重置；操作列固定在右侧，不能隐藏
固定列只有放不下、出现横向滚动时，固定列边缘才出现细线和内容渐隐，不用投影
悬停与选中悬停整行换浅底；选中是很浅的季节色；固定列跟着变色
长文本标题省略号截断，悬停且确实被截断时才显示完整标题；精选用标题后的小星标表示
分页左侧共几条、第几页与每页条数（10 / 20 / 50），右侧页码；切换条数回到第 1 页
