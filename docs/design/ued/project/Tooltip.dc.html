文字提示

tooltip

给图标按钮补一句名称或快捷键，给被截断的文字补上全文。只放文字，不放链接和按钮；需要点的内容用弹出层。

演示

Tooltip · delayDuration 0 · Arrow

默认带箭头，「形态」可以换成不带箭头。指针移到工具栏图标上立刻浮出；在相邻图标之间移动，同一个提示框滑过去并换字；移开后往回退并淡出。点按钮会收起提示。「发布」不可用时，提示写明原因。右边列表里只有被截断的标题才会出现提示。也可以用 Tab 在按钮之间移动。

结构

和菜单、弹出层同一种纸片，不加描边；箭头指着它说明的那个按钮。

时机

delayDuration 0
出现指针移上去立刻浮出 150ms，不等待
相邻切换提示还在时移到另一个触发器，同一个提示框滑到新位置并换字，180ms，不重新出现
收起指针离开 60ms 后往触发器退 4px 并淡出，120ms；这 60ms 内移到相邻按钮就直接滑过去。按下触发器或 Esc 立刻收起
键盘Tab 聚焦时立刻出现，失焦就收起
截断只有文字确实被截断时才出现，内容是完整的那一句；没截断就不出现，免得重复
触屏没有悬停，不出现：所以名称必须同时写在 aria-label 或可见文字里，不能只靠提示

里面要点的东西（链接、按钮）用弹出层；需要让人读完的提醒用内联提示；已经写在按钮上的文字不要再提示一遍。

行为与读屏

同时一个整页同时只显示一个提示
位置默认在上方居中；离窗口边不足 8 时往里平移；上方放不下时换到下方
不可点提示本身不接收指针，不能把链接、按钮放进去
不可用的按钮不可用的按钮收不到悬停，用一层外壳接住悬停，按钮本身 aria-disabled 并用 aria-describedby 指向原因
读屏图标按钮用 aria-label 命名；提示 role="tooltip"，说明性的内容用 aria-describedby 关联
