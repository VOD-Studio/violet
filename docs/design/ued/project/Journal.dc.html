踩坑macOS · zsh已解决#shell #macos
macOS 的 zsh 把 === 当命令查找
现象shell 脚本里用 echo 输出 === 当分隔符，直接报错。
根因zsh 把以 = 开头的词当作命令路径去展开。
修法分隔符换成普通字符串，或拆成两条命令。
echo "--SEP--"
踩坑Biome · React已解决#biome #react
biome check --unsafe 会删掉语义必要的 effect 依赖
现象useEffect 的 [activeTag] 依赖被判为多余，自动修复直接删掉，标签切换后旧游标页混进新流。
修法这类 effect 不用 --unsafe 自动修复，保留依赖并写明原因。
踩坑SQLite已解决#sqlite #testing
SQLite CURRENT_TIMESTAMP 只有秒级分辨率
现象仓储契约测试按插入顺序断言 created_at DESC，偶发翻转。
根因默认精度是秒，同秒插入的行排序退化为 id（uuid）排序。
