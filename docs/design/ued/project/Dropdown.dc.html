下拉菜单

dropdown · foundation

导航上的悬停菜单：指针停一下就展开，在相邻菜单之间移动时面板直接变形过去。每一项是图标块、粗体名称和一行说明，点进去是一个页面。

演示

DropdownGroup · Dropdown · openDelay · closeDelay

把指针移到导航上的「文章」「更多」「关于」。第一次停 80ms 才展开；展开之后在三者之间移动，面板直接变形过去，不收起再打开。离开 140ms 后收起，收起后 400ms 内再移回来会立刻展开。也可以 Tab 到导航上按 ↓。

时机

openDelay 80 · closeDelay 140 · skipDelay 400

悬停菜单靠时机决定好不好用：太快会在指针路过时乱弹，太慢让人觉得迟钝。

展开延迟80ms：指针只是路过导航时不展开
收起延迟140ms：指针斜着移向面板、短暂离开触发器时不收起
预热同一组里有菜单开着，或刚收起不到 400ms，移到另一个触发器立刻展开，不再等 80ms
接力变形已展开时移到相邻触发器，面板从当前位置和尺寸变形到新菜单，380ms，cubic-bezier(.45,0,.2,1)；内容按最终宽度排好，变形时文字不重排，新旧内容交叉淡化
Esc 之后按 Esc 收起后，指针要先离开再进入才会重新展开
触屏没有悬停：点触发器展开，点外面收起；不使用预热和接力

键盘

↓ / Enter / 空格在触发器上展开，焦点进第一项
↑ ↓在项之间移动，到头循环；高亮跟着焦点走
Home / End第一项 / 最后一项
Esc收起，焦点回到触发器
Tab收起，焦点去导航里的下一个元素
读屏触发器 aria-haspopup="menu" 与 aria-expanded；面板 role="menu"，项是链接 role="menuitem"

动效

展开从导航下方 6px 处浮出并淡入，收起往回退 4px 并淡出。组件库现在的代码是从上往下裁切揭开，这里改成浮出；菜单之间的接力变形保持不变。
