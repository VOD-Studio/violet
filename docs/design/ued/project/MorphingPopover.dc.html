变形弹出层

morphing-popover · 新增单元

触发它的按钮本身长成面板：外形从按钮的位置、大小和圆角长出来，内容按最终大小排好、晚一拍浮现；收起时原路缩回按钮。只给小而独立的按钮用，现有的弹出层、菜单、对话框不受影响。

结构

外形、按钮上的字、面板内容、软影是四个独立的部分，各走各的时间；只有外形在动，内容从头到尾都按最终大小排好。

晴天
起点外形就是按钮：同样的位置、大小和胶囊圆角
晴天
途中按住左上角往右下长；按钮上的字模糊淡出，面板内容还没出现
到位圆角收到 16；内容由虚变实，最后一段软影浮起来
触发器

必须是一个独立的形状：有底色的胶囊或圆钮。透明的图标按钮长不出来，没有起点。

锚点

面板盖住触发器，固定触发器的一个角（默认左上），朝空间大的方向长；放不下时换成别的角。

外形

只动裁切和底色：从按钮的矩形与圆角长到面板，底色从按钮的底色过渡到纸色。不缩放，文字不会变形。

内容

按钮上的字先模糊淡出；面板内容晚一拍由模糊 4px 变清晰。收回时顺序反过来，按钮上的字最后浮现。

行为

什么时候用触发器小而独立，打开的内容只和它有关，而且面板可以盖住它：状态卡、回应、快速写、日期胶囊这类
打开按下有 50ms 的按下态，然后外形用和灵动岛一样的弹簧长出（stiffness 340、damping 32，约 480ms）
收回内容先淡掉 60ms、软影同时消失，外形用先快后慢的曲线 220ms 收回按钮，按钮上的字最后 100ms 浮现
打断长到一半再点，从当前形状直接收回；收回途中再点，从当前形状再长出来，都不跳回起点
接力面板可以再长成下一个面板：表情条长成完整的表情面板，锚点不变；从接力的面板关闭时，直接收回到最初的按钮
关闭点面板里原来按钮的位置、点外面、Esc；焦点回到触发器
不打断页面没有遮罩，不锁滚动；同时只开一个，打开另一个时前一个直接收回
读屏触发器 aria-expanded 与 aria-controls；面板按内容取角色：状态卡 dialog，表情条 listbox
减弱动态不做变形，面板直接淡入 100ms，收起淡出 100ms

动效

和对话框的「从按钮展开」是同一套：外形先动，内容晚一拍；区别是这里面板贴着按钮长，不移动位置，弹簧与灵动岛一致。

规格

触发器高 28–40 的胶囊或圆钮，必须有底色；按下态底色加深 4%
面板宽 240–400；圆角：单行的条保持胶囊，多行的面板 16；纸色底，唯一软影
锚点偏移面板比触发器高时，单行的条上下居中对齐触发器（表情条上移 6），多行的面板对齐触发器的角
时长打开约 480ms（弹簧）；收回 220ms (.32,.72,0,1)；内容 220ms / 60ms；按钮字 100ms
层级40，与弹出层同层；同一时刻只有一个
实现外形用 clip-path inset 与 background-color 的 Web Animations；打断时读取当前的计算值作为新动画的起点
