对话框

dialog · modal

把当前页面压暗，让人专心做完一件小事：填一张短表、读完一段需要知道的说明。内容长、或者需要一边看页面一边改，换侧边面板；只是确认一下，用确认框。

行为

打开焦点落到第一个输入框；没有输入框时落到主按钮
关闭Esc、点遮罩、关闭按钮、取消四种方式等价；有未保存的修改时底栏先问一句，不直接关掉
焦点Tab 只在框内循环；关闭后焦点回到打开它的按钮
滚动背后的页面锁住，滚动条的位置保留，页面不左右跳；内容区滚到头不带动背后
嵌套框里的选择器、弹出层、文字提示点选不会关掉对话框；对话框上最多再叠一层确认框
提交主按钮触发校验，错误写在对应字段下方，焦点移到第一个出错的字段；成功后关闭并发一条轻提示
读屏role="dialog"，aria-labelledby 指向标题，aria-describedby 指向说明；背后的内容对读屏隐藏

动效

遮罩和面板是两层：遮罩只负责把页面推远，面板必须有自己的变化，并且晚一拍，否则两者一起淡入，看起来像同一层。下面跟着上方「动效」的选择切换。

从按钮展开（推荐）

点的那个按钮本身变成对话框。对话框先按最终大小排好，从按钮那块大小、胶囊圆角的区域露出来，一边长大一边从按钮的位置移到中间；底色从按钮的浅底过渡到纸色，到位前最后一段软影才浮起来。内容不缩放，只淡入，所以文字不会变形或抖动。关掉时内容先淡掉，外形用先快后慢的曲线收回按钮，比打开快近一半，按钮上的字随后淡入。

落位

没有触发按钮时用：快捷键打开、会话过期提醒这类由系统发起的对话框。面板从下方 14px 处落到原位，带一点回弹，同时淡入；标题、内容、底栏依次跟上，各晚 40ms。
