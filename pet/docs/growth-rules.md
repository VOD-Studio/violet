# 成长规则：经验、性格与进化

#526 的实现说明。数值是**暂定默认值**，与 `parameters.md` 的节奏一起在试玩后调整；规则行为由 `crates/pet-core/tests/growth.rs` 的 19 项测试覆盖，关键防护用变异检查确认能被测试抓到。

## 三类状态分开建模

| 类别 | 存储 | 时间尺度 |
|---|---|---|
| 身体状态：饱食、精力、健康 | `Pet` 字段 | 分钟到天 |
| 短期情绪 | **不存储**，由身体状态派生（病、饿、累、开心、平静） | 即时 |
| 长期性格 | `growth.traits`，三个维度 | 周 |

情绪不落库，所以一次饥饿不会变成永久状态，也无法被刷。

## 经验与等级

- 只有**有成本**的动作给经验：喂食 +1，玩耍 +2。休息与等待无成本，不给经验（测试：200 次休息/等待经验仍为 0）。
- 奖励经验由 `grant` 发放，单次至多 100；累计至多 1500。
- 等级阈值（累计经验）：1 级 0，2 级 20，3 级 50，4 级 100，5 级 180，6 级 300，7 级 480，8 级 720，9 级 1050，10 级 1500。

## 性格

- 三个维度：好奇、亲和、沉稳，各 0 到 1000。
- **出生底色**由基因的后三个字节决定，落在 300 到 699，创建后不变，写入黄金出生向量。
- 漂移规则：
  - 玩耍 → 好奇 +6；喂食 → 亲和 +6；休息 → 沉稳 +6；治疗 → 亲和 +10；带主题的奖励 → 好奇 +4。
  - **只向上漂移**。每个维度每天最多漂移 30 点（按逻辑时间 / 1440 计天），总偏离不超过底色 +200。
- 效果：一天内的短时重复刺激最多改变 30 点；坚持同一种相处方式约一周可达到上限；没有练习的维度保持在底色。测试覆盖单日爆发、60 天持续、未练习维度不变、长期饥饿不改变性格。
- 已知限制：不会向下漂移，因此偏离只增不减。若需要“疏于相处则回落”，应作为后续规则单独评审，而不是在这里默默加入。

## 进化

三个阶段：幼体 → 少年 → 成年。进化**永不自动发生**，必须主人选择，并消耗 3 份食物。

| 阶段 | 分支 | 条件 |
|---|---|---|
| 幼体 → 少年 | 好奇 | 3 级，好奇 ≥ 550 |
| | 温柔 | 3 级，亲和 ≥ 550 |
| | 稳健 | 3 级（默认路径） |
| 少年 → 成年 | 贤者 | 7 级，最高主题计数 ≥ 20，好奇 ≥ 600 |
| | 守护者 | 7 级，亲和 ≥ 600，沉稳 ≥ 550 |
| | 漫游者 | 7 级（默认路径） |
| | 辉耀（后天罕见） | 9 级，三维性格均 ≥ 650，主题计数合计 ≥ 60 且至少 3 个主题 |

- `evolution_options` 返回当前阶段每个分支是否合格，以及未满足的条件还差多少（等级、好奇、亲和、沉稳、主题、主题多样性、食物）。同一类缺项只列要求最高的一条。
- 不合格的进化返回 `not_eligible`，**不扣任何资源**；合格的进化只扣一次，同一请求标识重放不重复扣费（测试覆盖）。
- 分支必须属于当前阶段，否则拒绝；成年后没有后续分支。
- **后天罕见**记录在 `growth.acquired_rarity`，不修改出生稀有度、物种、基因或身份。出生记录仍可按原样重算（测试：走完整条路径后重新派生出生，稀有度与基因不变）。

## 主题倾向

- 由接入方映射的主题标签，经 `grant` 记录，至多 8 项，每项 32 字节以内。
- 满 8 项后淘汰计数最低、最早加入的一项，规则确定、无随机。
- 主题只在资格形成时由接入方固定；核心不重新分类，也不依赖 AI。

## 发放奖励（`grant`）

核心只校验单次上限（经验 ≤ 100，食物 ≤ 10，药品 ≤ 3，主题非空且 ≤ 32 字节），**不决定谁有资格**——资格、去重与每日上限属于宠物服务（#527，ADR-0021）。库存上限：食物 99、药品 9。与 `act` 一样先结算逻辑时间、以请求标识幂等、拒绝死亡个体。
